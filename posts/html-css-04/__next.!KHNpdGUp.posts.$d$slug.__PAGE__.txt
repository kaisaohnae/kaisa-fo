3:T23cf,<h1>CSS Grid로 행과 열 동시에 잡기</h1>
<blockquote>
<p>요약: 행과 열을 함께 정해야 할 때 Grid로 페이지 골격과 카드 목록을 만들고, fr·영역 이름으로 칸을 나눈다.</p>
</blockquote>
<hr>
<h2>언제 Grid를 쓰는가</h2>
<p>행과 열을 동시에 제어할 때 Grid를 쓴다. 대시보드, 갤러리, 헤더·사이드·본문이 있는 페이지 골격이 해당한다.</p>
<p>한 줄 정렬만 필요하면 Flexbox면 된다. 카드 바깥 칸은 Grid, 카드 안 제목·버튼 정렬은 Flex로 나누면 역할이 섞이지 않는다.</p>
<hr>
<h2>트랙이 칸의 크기이다</h2>
<p>부모에 <code>display: grid</code>를 주면 자식이 칸에 들어간다. <code>grid-template-columns</code>가 열, <code>grid-template-rows</code>가 행이다. 이 선을 트랙이라고 한다.</p>
<pre><code class="hljs language-css"><span class="hljs-selector-class">.page</span> {
  <span class="hljs-attribute">display</span>: grid;
  <span class="hljs-attribute">grid-template-columns</span>: <span class="hljs-number">240px</span> <span class="hljs-number">1</span>fr;
  <span class="hljs-attribute">grid-template-rows</span>: auto <span class="hljs-number">1</span>fr auto;
  <span class="hljs-attribute">min-height</span>: <span class="hljs-number">100</span>dvh;
  <span class="hljs-attribute">gap</span>: <span class="hljs-number">1rem</span>;
}</code></pre>
<p>왼쪽 열은 240px로 고정이다. 오른쪽 열은 <code>1fr</code>이라서 남은 가로를 모두 가져간다. 행은 헤더·푸터 높이만큼 <code>auto</code>, 본문 행은 남은 세로를 가져간다.</p>
<table>
<thead>
<tr>
<th>단위</th>
<th>하는 일</th>
</tr>
</thead>
<tbody><tr>
<td><code>fr</code></td>
<td>남은 공간을 비율로 나눈다. <code>1fr 2fr</code>이면 1:2</td>
</tr>
<tr>
<td><code>minmax(0, 1fr)</code></td>
<td>fr 칸이 내용 때문에 넘치지 않게 하한을 0으로 둔다</td>
</tr>
<tr>
<td><code>auto</code></td>
<td>내용 높이나 너비에 맞춘다</td>
</tr>
<tr>
<td><code>repeat(auto-fit, minmax(16rem, 1fr))</code></td>
<td>폭에 따라 열 개수를 늘린다</td>
</tr>
</tbody></table>
<p><code>minmax(0, 1fr)</code>을 쓰는 이유는 Flex의 <code>min-width: 0</code>과 같다. 그리드 칸의 최소 크기가 내용 너비면 가로 스크롤이 생긴다.</p>
<hr>
<h2>반응형 카드 그리드</h2>
<p>열 개수를 미디어 쿼리로 일일이 바꾸지 않아도 된다. 칸의 최소 너비만 정하면 브라우저가 열 수를 맞춘다.</p>
<pre><code class="hljs language-html"><span class="hljs-tag">&lt;<span class="hljs-name">ul</span> <span class="hljs-attr">class</span>=<span class="hljs-string">&quot;cards&quot;</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>카드 1<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>카드 2<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">li</span>&gt;</span>카드 3<span class="hljs-tag">&lt;/<span class="hljs-name">li</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">ul</span>&gt;</span></code></pre>
<pre><code class="hljs language-css"><span class="hljs-selector-class">.cards</span> {
  <span class="hljs-attribute">display</span>: grid;
  <span class="hljs-attribute">grid-template-columns</span>: <span class="hljs-built_in">repeat</span>(auto-fit, <span class="hljs-built_in">minmax</span>(<span class="hljs-number">16rem</span>, <span class="hljs-number">1</span>fr));
  <span class="hljs-attribute">gap</span>: <span class="hljs-number">1rem</span>;
}</code></pre>
<p><code>auto-fit</code>은 빈 열을 접는다. <code>auto-fill</code>은 빈 열을 남겨 둔다. 카드가 적을 때 칸이 늘어나길 원하면 <code>auto-fit</code>이다.</p>
<hr>
<h2>이름 있는 영역으로 배치</h2>
<p>칸 좌표 대신 영역 이름을 붙이면 미디어 쿼리에서 재배치하기 쉽다.</p>
<pre><code class="hljs language-html"><span class="hljs-tag">&lt;<span class="hljs-name">div</span> <span class="hljs-attr">class</span>=<span class="hljs-string">&quot;layout&quot;</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">header</span> <span class="hljs-attr">class</span>=<span class="hljs-string">&quot;header&quot;</span>&gt;</span>헤더<span class="hljs-tag">&lt;/<span class="hljs-name">header</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">nav</span> <span class="hljs-attr">class</span>=<span class="hljs-string">&quot;nav&quot;</span>&gt;</span>내비<span class="hljs-tag">&lt;/<span class="hljs-name">nav</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">main</span> <span class="hljs-attr">class</span>=<span class="hljs-string">&quot;main&quot;</span>&gt;</span>본문<span class="hljs-tag">&lt;/<span class="hljs-name">main</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">footer</span> <span class="hljs-attr">class</span>=<span class="hljs-string">&quot;footer&quot;</span>&gt;</span>푸터<span class="hljs-tag">&lt;/<span class="hljs-name">footer</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">div</span>&gt;</span></code></pre>
<pre><code class="hljs language-css"><span class="hljs-selector-class">.layout</span> {
  <span class="hljs-attribute">display</span>: grid;
  <span class="hljs-attribute">grid-template-columns</span>: <span class="hljs-number">12rem</span> <span class="hljs-number">1</span>fr;
  <span class="hljs-attribute">grid-template-areas</span>:
    <span class="hljs-string">&quot;header header&quot;</span>
    <span class="hljs-string">&quot;nav    main&quot;</span>
    <span class="hljs-string">&quot;footer footer&quot;</span>;
  <span class="hljs-attribute">min-height</span>: <span class="hljs-number">100</span>dvh;
}

<span class="hljs-selector-class">.header</span> { <span class="hljs-attribute">grid-area</span>: header; }
<span class="hljs-selector-class">.nav</span>    { <span class="hljs-attribute">grid-area</span>: nav; }
<span class="hljs-selector-class">.main</span>   { <span class="hljs-attribute">grid-area</span>: main; }
<span class="hljs-selector-class">.footer</span> { <span class="hljs-attribute">grid-area</span>: footer; }

<span class="hljs-keyword">@media</span> (<span class="hljs-attribute">max-width</span>: <span class="hljs-number">640px</span>) {
  <span class="hljs-selector-class">.layout</span> {
    <span class="hljs-attribute">grid-template-columns</span>: <span class="hljs-number">1</span>fr;
    <span class="hljs-attribute">grid-template-areas</span>:
      <span class="hljs-string">&quot;header&quot;</span>
      <span class="hljs-string">&quot;main&quot;</span>
      <span class="hljs-string">&quot;nav&quot;</span>
      <span class="hljs-string">&quot;footer&quot;</span>;
  }
}</code></pre>
<p>좁은 화면에서 내비를 본문 아래로 내리는 변경이 문자열 한 덩어리로 끝난다. <code>grid-column: 1 / 3</code> 같은 숫자 좌표보다 읽기 쉽다.</p>
<hr>
<h2>Flex와 나누는 기준</h2>
<table>
<thead>
<tr>
<th></th>
<th>Flex</th>
<th>Grid</th>
</tr>
</thead>
<tbody><tr>
<td>차원</td>
<td>한 방향</td>
<td>행과 열</td>
</tr>
<tr>
<td>강점</td>
<td>주축 여백 나누기, 아이템 늘리기</td>
<td>트랙 크기, 영역, 겹침</td>
</tr>
<tr>
<td>함께 쓰는 예</td>
<td>카드 안 헤더와 버튼</td>
<td>카드가 올라가는 바깥 칸</td>
</tr>
</tbody></table>
<p>페이지 골격은 Grid, 컴포넌트 내부 한 줄은 Flex이다. 둘 다 <code>gap</code>으로 간격을 준다.</p>
<hr>
<h2>흔한 실수</h2>
<ul>
<li>한 줄 툴바를 Grid로 짠다. Flex가 짧다.</li>
<li><code>1fr</code> 칸에서 긴 코드 블록이 페이지를 밀어 낸다. 그 열을 <code>minmax(0, 1fr)</code>로 바꾼다.</li>
<li><code>auto-fit</code>과 <code>auto-fill</code>을 구분하지 않는다. 카드가 적을 때 칸이 커지길 원하면 <code>auto-fit</code>이다.</li>
<li>자식 순서만 바꾸고 영역 이름을 안 쓴다. 반응형 재배치는 <code>grid-template-areas</code>가 덜 깨진다.</li>
<li>Grid와 Flex에 아이템 <code>margin</code>을 섞는다. 부모 <code>gap</code>으로 통일한다.</li>
</ul>
<hr>
<h2>정리</h2>
<p>Grid는 행과 열의 선을 먼저 긋는 도구이다. 페이지 뼈대는 트랙과 영역 이름으로 두고, 칸 안의 정렬은 Flex에 맡긴다. <code>fr</code>과 <code>minmax(0, 1fr)</code>만 익혀도 넘침의 상당수는 줄어든다.</p>
<hr>
<h2>연습</h2>
<ol>
<li>헤더·사이드바·본문·푸터를 <code>grid-template-areas</code>로 만들고, 640px 이하에서 사이드바를 본문 아래로 옮긴다.</li>
<li>카드 목록을 <code>repeat(auto-fit, minmax(16rem, 1fr))</code>로 두고 창 폭을 줄여 열 수가 바뀌는지 확인한다.</li>
<li><code>1fr</code> 열 안에 긴 URL을 넣고, <code>minmax(0, 1fr)</code> 전후에 가로 스크롤이 생기는지 비교한다.</li>
</ol>
