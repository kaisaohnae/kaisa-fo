3:T275b,<h1>React Native와 Expo로 시작하기</h1>
<blockquote>
<p>요약: Expo와 TypeScript로 React Native 프로젝트를 만들고, 첫 화면이 뜨기까지의 기본 지도를 잡는다.</p>
</blockquote>
<hr>
<h2>1. 왜 Expo로 시작하나</h2>
<p>React Native는 JavaScript/TypeScript로 <strong>iOS·Android 네이티브 UI</strong>를 만드는 프레임워크다. 웹의 DOM 대신 네이티브 뷰를 그린다. 컴포넌트·훅·상태 모델은 React와 같다.</p>
<p><strong>Expo</strong>는 그 위에 올라가는 개발·빌드·배포 툴체인이다. 네이티브 프로젝트를 직접 만지지 않고도 앱을 만들고, 나중에 스토어 빌드까지 이어갈 수 있다.</p>
<p>지금은 Expo가 “토이 전용”이 아니다. 학습과 프로덕션 모두 <strong>Expo + TypeScript</strong>를 기본선으로 둔다.</p>
<table>
<thead>
<tr>
<th>구분</th>
<th>React (웹)</th>
<th>React Native</th>
</tr>
</thead>
<tbody><tr>
<td>렌더</td>
<td>HTML/CSS</td>
<td>네이티브 뷰</td>
</tr>
<tr>
<td>스타일</td>
<td>CSS</td>
<td>StyleSheet + Flex</td>
</tr>
<tr>
<td>라우팅</td>
<td>react-router 등</td>
<td>Expo Router</td>
</tr>
<tr>
<td>번들</td>
<td>Vite/Webpack</td>
<td>Metro</td>
</tr>
</tbody></table>
<hr>
<h2>2. 핵심 개념</h2>
<p><strong>Managed Expo</strong>가 기본이다. 네이티브 폴더(<code>ios/</code>, <code>android/</code>)를 직접 관리하지 않는다. 커스텀 네이티브가 필요하면 config plugin과 prebuild로 확장한다.</p>
<table>
<thead>
<tr>
<th>항목</th>
<th>Expo</th>
<th>Bare CLI</th>
</tr>
</thead>
<tbody><tr>
<td>시작</td>
<td>빠르다</td>
<td>느리다</td>
</tr>
<tr>
<td>스토어 빌드</td>
<td>EAS Build</td>
<td>Xcode/Gradle 직접</td>
</tr>
<tr>
<td>JS 핫픽스</td>
<td>EAS Update</td>
<td>직접 구성</td>
</tr>
<tr>
<td>네이티브 모듈</td>
<td>config plugin</td>
<td>수동 연동</td>
</tr>
</tbody></table>
<p><strong>EAS</strong>(Expo Application Services)는 Expo의 클라우드 빌드·제출·업데이트 서비스다. 지금은 “나중에 쓴다” 정도만 기억하면 된다. 배포 문에서 다룬다.</p>
<p>New Architecture는 최근 Expo SDK에서 기본/권장이다.</p>
<ul>
<li><strong>Fabric</strong>: 새 렌더러</li>
<li><strong>TurboModules</strong>: 네이티브 모듈 호출</li>
<li><strong>JSI</strong>: JS와 네이티브의 저수준 연결</li>
</ul>
<p>브릿지 병목이 줄었다는 점만 알면 시작에는 충분하다.</p>
<hr>
<h2>3. 예제</h2>
<p>환경: Node.js LTS(20+), Git, Android Studio 또는 Xcode(macOS). 실기기는 <strong>Expo Go</strong> 앱으로 바로 실행할 수 있다.</p>
<pre><code class="hljs language-bash">npx create-expo-app@latest my-app --template tabs
<span class="hljs-built_in">cd</span> my-app
npx expo start</code></pre>
<p>TypeScript + Expo Router 템플릿을 고른다. <code>tabs</code>가 그 조합이다.</p>

<p>웹 CSS 감각을 그대로 가져오면 레이아웃이 깨진다. Flex 기본 방향이 <strong>세로(<code>column</code>)</strong> 인 점부터 다시 익힌다. 다음 글에서 다룬다.</p>
<hr>
<h2>5. 정리</h2>
<p>React Native 시작은 네이티브 프로젝트 생성이 아니다. <strong>Expo + TypeScript + Expo Router</strong>로 실행 루프를 고정하는 일이다.</p>
<ul>
<li>Expo는 RN 툴체인이다. 나중에 EAS로 빌드·OTA를 붙인다.</li>
<li>화면은 네이티브 뷰다. HTML/CSS가 아니다.</li>
<li>New Architecture는 켜 두고, 세부 API는 필요할 때 본다.</li>
</ul>
<h2>연습</h2>
<ol>
<li>Expo 프로젝트를 만들고 에뮬레이터 또는 실기기에서 실행한다.</li>
<li>홈 화면에 앱 이름과 버전 텍스트를 표시한다.</li>
<li><code>app.json</code>의 <code>name</code>, <code>scheme</code>을 바꾸고 반영을 확인한다.</li>
<li><code>User</code> 타입과 그 값을 그리는 작은 컴포넌트를 만든다.</li>
</ol>
