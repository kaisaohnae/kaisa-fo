3:T249f,<h1>Flexbox로 한 줄 레이아웃 잡기</h1>
<blockquote>
<p>요약: 한 줄 또는 한 열로 아이템을 나열할 때 Flexbox로 축·정렬·간격을 맞춰 내비·툴바·카드 액션을 배치한다.</p>
</blockquote>
<hr>
<h2>언제 Flexbox를 쓰는가</h2>
<p>한 줄 또는 한 열로 아이템을 나열하고 정렬할 때 Flexbox를 쓴다. 축을 정한 뒤 정렬과 간격만 맞추면 된다.</p>
<p>내비, 툴바, 폼 한 줄, 카드 안의 제목과 버튼이 해당한다. 행과 열을 동시에 설계해야 하면 Grid를 본다. Flex는 1차원 도구이다.</p>
<hr>
<h2>축을 먼저 정한다</h2>
<p>부모에 <code>display: flex</code>를 주면 자식이 flex 아이템이 된다. <code>flex-direction</code>이 주축이다. 기본값은 <code>row</code>(가로). <code>column</code>이면 세로가 주축이다.</p>
<p>교차축은 주축에 수직인 방향이다. <code>row</code>면 교차축은 세로이다.</p>
<table>
<thead>
<tr>
<th>속성</th>
<th>하는 일</th>
</tr>
</thead>
<tbody><tr>
<td><code>flex-direction</code></td>
<td>주축을 가로로 둘지 세로로 둘지</td>
</tr>
<tr>
<td><code>justify-content</code></td>
<td>주축 방향 여백을 어떻게 나눌지</td>
</tr>
<tr>
<td><code>align-items</code></td>
<td>교차축에서 아이템을 어디에 붙일지</td>
</tr>
<tr>
<td><code>flex-wrap</code></td>
<td>공간 부족 시 다음 줄로 넘길지</td>
</tr>
<tr>
<td><code>gap</code></td>
<td>아이템 사이 간격. margin을 아이템마다 주지 않는다</td>
</tr>
</tbody></table>
<p><code>justify-content: space-between</code>은 양 끝을 붙이고 남는 가로 여백을 사이에 넣는다. <code>center</code>는 남는 여백을 양쪽에 균등히 둔다. <code>flex-start</code>는 여백을 끝으로 몰고 아이템을 시작점에 붙인다.</p>
<p><code>align-items: center</code>는 세로(교차축) 가운데에 맞춘다. 높이가 다른 아이콘과 텍스트를 한 줄에 둘 때 자주 쓴다.</p>
<hr>

<h2>아이템이 늘어나고 줄어드는 방식</h2>
<p>아이템 쪽 속성은 <code>flex-grow</code>, <code>flex-shrink</code>, <code>flex-basis</code>이다. 단축은 <code>flex</code>이다.</p>
<pre><code class="hljs language-css"><span class="hljs-selector-class">.grow</span> {
  <span class="hljs-attribute">flex</span>: <span class="hljs-number">1</span> <span class="hljs-number">1</span> auto;
}

<span class="hljs-selector-class">.fixed</span> {
  <span class="hljs-attribute">flex</span>: <span class="hljs-number">0</span> <span class="hljs-number">0</span> <span class="hljs-number">240px</span>;
}</code></pre>

<hr>
<h2>흔한 실수</h2>
<ul>
<li>2차원 페이지 골격을 Flex로 짠다. 행과 열이 같이 필요하면 Grid이다.</li>
<li><code>justify-content</code>와 <code>align-items</code>를 바꿔 쓴다. 주축 여백이 <code>justify</code>, 교차축 붙임이 <code>align</code>이다.</li>
<li>아이템마다 <code>margin-right</code>로 간격을 준다. 부모 <code>gap</code>으로 통일한다.</li>
<li>긴 제목이 옆 버튼을 밀어 낸다. 제목에 <code>min-width: 0</code>과 <code>overflow: hidden</code>을 검토한다.</li>
<li><code>flex: 1</code>만 쓰고 basis를 잊는다. 고정 폭이 필요하면 <code>flex: 0 0 240px</code>처럼 명시한다.</li>
</ul>
<hr>
<h2>정리</h2>
<p>Flex는 만능 그리드가 아니다. 한 줄 또는 한 열에서 여백을 나누는 도구이다. 주축을 정하고, <code>justify-content</code>로 그 방향 여백을 나누고, <code>align-items</code>와 <code>gap</code>으로 나머지 맞추면 된다.</p>
<hr>
<h2>연습</h2>
<ol>
<li>로고·링크 묶음·로그인 버튼이 있는 헤더를 Flex로 만든다. 링크는 왼쪽에 붙이고 버튼만 오른쪽으로 민다.</li>
<li><code>flex-direction: column</code>인 사이드바에서 <code>justify-content</code>를 바꿔 가며 항목이 어디에 붙는지 확인한다.</li>
<li>Flex 행 안의 긴 파일명을 <code>text-overflow: ellipsis</code>로 자르되, 잘리지 않으면 <code>min-width: 0</code>을 추가한다.</li>
</ol>
