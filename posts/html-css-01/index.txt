24:T2a0a,<h1>시맨틱 HTML로 문서 뼈대 잡기</h1>
<blockquote>
<p>요약: header·main·nav 같은 시맨틱 태그로 페이지 뼈대를 잡고, 스크린 리더와 검색엔진이 읽을 수 있는 HTML을 작성한다.</p>
</blockquote>
<hr>
<h2>언제 시맨틱 태그를 쓰는가</h2>
<p>화면은 <code>div</code>만으로도 만들 수 있다. 다만 태그에 역할을 넣으면 브라우저·스크린 리더·검색엔진이 같은 구조를 읽는다.</p>
<p>새 페이지를 시작할 때 먼저 뼈대를 정한다. 사이트 머리글, 본문, 내비, 바닥글을 <code>div</code>로 감싸지 말고 역할에 맞는 태그를 고른다.</p>
<p>선택자도 의미가 남는다. <code>.header</code> 클래스보다 <code>header</code> 태그가 의도를 더 짧게 전달한다.</p>
<hr>

<h2>링크와 버튼</h2>
<p>이동이면 <code>a</code>를 쓴다. 그 페이지에서 동작을 실행하면 <code>button</code>을 쓴다.</p>
<pre><code class="hljs language-html"><span class="hljs-tag">&lt;<span class="hljs-name">a</span> <span class="hljs-attr">href</span>=<span class="hljs-string">&quot;/login&quot;</span>&gt;</span>로그인 페이지로 이동<span class="hljs-tag">&lt;/<span class="hljs-name">a</span>&gt;</span>

<span class="hljs-tag">&lt;<span class="hljs-name">button</span> <span class="hljs-attr">type</span>=<span class="hljs-string">&quot;submit&quot;</span>&gt;</span>저장<span class="hljs-tag">&lt;/<span class="hljs-name">button</span>&gt;</span></code></pre>
<p>클릭 가능한 <code>div</code>에 <code>onclick</code>을 붙이면 키보드와 스크린 리더가 버튼을 인식하지 못한다. <code>div</code>로 버튼을 만들지 않는다.</p>
<p><code>nav</code>에는 이동 링크만 둔다. 검색 제출 버튼은 <code>nav</code>가 아니라 <code>form</code> 안에 둔다.</p>
<hr>
<h2>이미지와 대체 텍스트</h2>
<p>의미 있는 이미지는 무엇을 보여 주는지 <code>alt</code>에 적는다. 장식용 이미지는 <code>alt=&quot;&quot;</code>로 비운다. 스크린 리더가 장식을 읽지 않게 하기 위함이다.</p>
<pre><code class="hljs language-html"><span class="hljs-tag">&lt;<span class="hljs-name">img</span>
  <span class="hljs-attr">src</span>=<span class="hljs-string">&quot;/hero.webp&quot;</span>
  <span class="hljs-attr">alt</span>=<span class="hljs-string">&quot;공원에서 산책하는 강아지&quot;</span>
  <span class="hljs-attr">width</span>=<span class="hljs-string">&quot;800&quot;</span>
  <span class="hljs-attr">height</span>=<span class="hljs-string">&quot;450&quot;</span>
/&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">img</span> <span class="hljs-attr">src</span>=<span class="hljs-string">&quot;/divider.svg&quot;</span> <span class="hljs-attr">alt</span>=<span class="hljs-string">&quot;&quot;</span> /&gt;</span></code></pre>
<p><code>width</code>와 <code>height</code>를 넣으면 이미지가 로드되기 전에 자리를 잡는다. CLS(누적 레이아웃 이동)가 줄어든다.</p>
<p>아이콘만 있는 링크에는 텍스트 이름을 남긴다. 보이지 않아도 된다.</p>
<pre><code class="hljs language-html"><span class="hljs-tag">&lt;<span class="hljs-name">a</span> <span class="hljs-attr">href</span>=<span class="hljs-string">&quot;/settings&quot;</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">img</span> <span class="hljs-attr">src</span>=<span class="hljs-string">&quot;/gear.svg&quot;</span> <span class="hljs-attr">alt</span>=<span class="hljs-string">&quot;&quot;</span> /&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">span</span> <span class="hljs-attr">class</span>=<span class="hljs-string">&quot;sr-only&quot;</span>&gt;</span>설정<span class="hljs-tag">&lt;/<span class="hljs-name">span</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">a</span>&gt;</span></code></pre>
<hr>
<h2>흔한 실수</h2>
<ul>
<li><code>div</code>를 중첩해 헤더·본문·푸터를 표현한다. 역할 태그로 바꾼다.</li>
<li><code>main</code>을 여러 개 둔다. 한 문서에 하나다.</li>
<li>모든 구역을 <code>section</code>으로 감싼다. 제목이 있는 주제일 때만 쓴다.</li>
<li>장식 이미지에 <code>alt=&quot;이미지&quot;</code>처럼 빈 정보를 넣는다. 장식이면 빈 문자열이다.</li>
<li><code>span</code>이나 <code>div</code>로 제목만 크게 스타일한다. 제목이면 <code>h1</code>–<code>h6</code>이다.</li>
</ul>
<hr>
<h2>정리</h2>
<p>시맨틱 HTML은 화면을 꾸미는 단계가 아니다. 문서가 무엇인지를 브라우저와 보조 기술에 선언하는 일이다. 뼈대가 맞으면 CSS와 접근성은 그 위에 얹으면 된다.</p>
<hr>
<h2>연습</h2>
<ol>
<li>블로그 글 한 편을 <code>header</code> / <code>nav</code> / <code>main</code> / <code>article</code> / <code>footer</code>만으로 마크업한다. <code>div</code>는 쓰지 않는다.</li>
<li>사이트 로고 이미지와 장식 아이콘 이미지에 각각 알맞은 <code>alt</code>를 넣는다.</li>
<li>기존 페이지에서 <code>h1</code>이 몇 개인지, 제목 계층이 건너뛰어졌는지 확인한다.</li>
</ol>
