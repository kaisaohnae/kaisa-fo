3:T2d57,<h1>이벤트 대신 ICommand로 액션 연결하기</h1>
<blockquote>
<p>요약: 버튼 클릭을 코드비하인드가 아니라 ViewModel의 ICommand로 연결하고, CanExecute로 활성 상태를 맞추는 방법을 정리한다.</p>
</blockquote>
<hr>
<h2>1. 왜 Command인가</h2>
<p><code>Button.Click</code>을 <code>.xaml.cs</code>에 두면 저장·검증이 View에 붙는다. 창을 띄우지 않고 로직을 시험하기 어렵다.</p>
<p><code>ICommand</code>는 <strong>버튼이 실행할 일을 ViewModel에 맡기는 계약</strong>이다. XAML은 <code>Command=&quot;{Binding SaveCommand}&quot;</code>만 안다. 실행 가능 여부는 <code>CanExecute</code>가 버튼 <code>IsEnabled</code>와 연결된다.</p>
<p>언제 이벤트가 남나: 마우스 좌표, 드래그, 패스워드 박스처럼 바인딩이 약한 접착. 저장·검색·삭제 같은 도메인 동작은 명령이다.</p>
<hr>
<h2>2. 핵심 개념</h2>
<table>
<thead>
<tr>
<th>구성</th>
<th>한 줄</th>
</tr>
</thead>
<tbody><tr>
<td><code>ICommand.Execute</code></td>
<td>클릭 시 할 일</td>
</tr>
<tr>
<td><code>ICommand.CanExecute</code></td>
<td>지금 실행 가능한지. false면 버튼 비활성</td>
</tr>
<tr>
<td><code>CanExecuteChanged</code></td>
<td>가능 여부가 바뀌었다고 UI에 알린다</td>
</tr>
<tr>
<td><code>CommandParameter</code></td>
<td>목록 행 등 추가 인자를 명령에 넘긴다</td>
</tr>
<tr>
<td><code>[RelayCommand]</code></td>
<td>CommunityToolkit.Mvvm이 위 구현을 생성한다</td>
</tr>
</tbody></table>
<p><code>ICommand</code>는 WPF 네임스페이스 <code>System.Windows.Input</code>에 있다. ViewModel 프로젝트가 WPF를 참조하기 싫으면 툴킷의 <code>IRelayCommand</code>를 쓴다. 단일 프로젝트면 <code>ICommand</code>로 충분하다.</p>
<hr>
<h2>3. 동작하는 예: 저장 명령</h2>
<p><code>ViewModels/MainViewModel.cs</code>:</p>
<pre><code class="hljs language-csharp"><span class="hljs-keyword">using</span> CommunityToolkit.Mvvm.ComponentModel;
<span class="hljs-keyword">using</span> CommunityToolkit.Mvvm.Input;

<span class="hljs-keyword">namespace</span> <span class="hljs-title">MyApp.ViewModels</span>;

<span class="hljs-keyword">public</span> <span class="hljs-keyword">partial</span> <span class="hljs-keyword">class</span> <span class="hljs-title">MainViewModel</span> : <span class="hljs-title">ObservableObject</span>
{
    [<span class="hljs-meta">ObservableProperty</span>]
    [<span class="hljs-meta">NotifyCanExecuteChangedFor(nameof(SaveCommand))</span>]
    <span class="hljs-keyword">private</span> <span class="hljs-built_in">string</span> title = <span class="hljs-string">&quot;&quot;</span>;

    [<span class="hljs-meta">ObservableProperty</span>]
    <span class="hljs-keyword">private</span> <span class="hljs-built_in">string</span> status = <span class="hljs-string">&quot;대기&quot;</span>;

    [<span class="hljs-meta">RelayCommand(CanExecute = nameof(CanSave))</span>]
    <span class="hljs-function"><span class="hljs-keyword">private</span> <span class="hljs-keyword">void</span> <span class="hljs-title">Save</span>()</span>
    {
        Status = <span class="hljs-string">$&quot;저장됨: <span class="hljs-subst">{Title.Trim()}</span>&quot;</span>;
    }

    <span class="hljs-function"><span class="hljs-keyword">private</span> <span class="hljs-built_in">bool</span> <span class="hljs-title">CanSave</span>()</span> =&gt; Title.Trim().Length &gt; <span class="hljs-number">0</span>;

    [<span class="hljs-meta">RelayCommand</span>]
    <span class="hljs-function"><span class="hljs-keyword">private</span> <span class="hljs-keyword">void</span> <span class="hljs-title">Clear</span>()</span>
    {
        Title = <span class="hljs-string">&quot;&quot;</span>;
        Status = <span class="hljs-string">&quot;대기&quot;</span>;
    }
}</code></pre>
<ul>
<li><code>[RelayCommand]</code> on <code>Save</code> → <code>SaveCommand</code> 속성 생성</li>
<li><code>CanExecute = nameof(CanSave)</code> → 비어 있으면 저장 버튼 비활성</li>
<li><code>[NotifyCanExecuteChangedFor(nameof(SaveCommand))]</code> → <code>Title</code>이 바뀔 때 <code>CanExecute</code>를 다시 묻는다</li>
</ul>
<p>XAML:</p>
<pre><code class="hljs language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">StackPanel</span> <span class="hljs-attr">Margin</span>=<span class="hljs-string">&quot;16&quot;</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">TextBox</span> <span class="hljs-attr">Text</span>=<span class="hljs-string">&quot;{Binding Title, UpdateSourceTrigger=PropertyChanged}&quot;</span> /&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">Button</span> <span class="hljs-attr">Content</span>=<span class="hljs-string">&quot;저장&quot;</span> <span class="hljs-attr">Command</span>=<span class="hljs-string">&quot;{Binding SaveCommand}&quot;</span> <span class="hljs-attr">Margin</span>=<span class="hljs-string">&quot;0,8,0,0&quot;</span> /&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">Button</span> <span class="hljs-attr">Content</span>=<span class="hljs-string">&quot;지우기&quot;</span> <span class="hljs-attr">Command</span>=<span class="hljs-string">&quot;{Binding ClearCommand}&quot;</span> /&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">TextBlock</span> <span class="hljs-attr">Text</span>=<span class="hljs-string">&quot;{Binding Status}&quot;</span> <span class="hljs-attr">Margin</span>=<span class="hljs-string">&quot;0,8,0,0&quot;</span> /&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">StackPanel</span>&gt;</span></code></pre>
<p>비동기:</p>
<pre><code class="hljs language-csharp">[<span class="hljs-meta">RelayCommand</span>]
<span class="hljs-function"><span class="hljs-keyword">private</span> <span class="hljs-keyword">async</span> Task <span class="hljs-title">SaveAsync</span>(<span class="hljs-params">CancellationToken cancellationToken</span>)</span>
{
    Status = <span class="hljs-string">&quot;저장 중&quot;</span>;
    <span class="hljs-keyword">await</span> Task.Delay(<span class="hljs-number">400</span>, cancellationToken);
    Status = <span class="hljs-string">&quot;저장됨&quot;</span>;
}</code></pre>
<p>생성 이름은 <code>SaveCommand</code>다 (<code>SaveAsyncCommand</code>가 아니다). UI 스레드를 막지 않으려면 <code>async</code> 명령을 쓴다. <code>Task.Delay</code> 자리는 실제 I/O다.</p>
<hr>
<h2>4. 파라미터와 목록</h2>
<p>행 삭제:</p>
<pre><code class="hljs language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">Button</span> <span class="hljs-attr">Content</span>=<span class="hljs-string">&quot;삭제&quot;</span>
        <span class="hljs-attr">Command</span>=<span class="hljs-string">&quot;{Binding DataContext.RemoveCommand, RelativeSource={RelativeSource AncestorType=ListBox}}&quot;</span>
        <span class="hljs-attr">CommandParameter</span>=<span class="hljs-string">&quot;{Binding}&quot;</span> /&gt;</span></code></pre>
<p>ViewModel:</p>
<pre><code class="hljs language-csharp">[<span class="hljs-meta">RelayCommand</span>]
<span class="hljs-function"><span class="hljs-keyword">private</span> <span class="hljs-keyword">void</span> <span class="hljs-title">Remove</span>(<span class="hljs-params">UserItem item</span>)</span> =&gt; Users.Remove(item);</code></pre>
<p><code>CommandParameter=&quot;{Binding}&quot;</code>은 그 행의 <code>UserItem</code>이다. 행 템플릿의 DataContext가 항목이라, 부모 ViewModel 명령은 <code>RelativeSource</code>로 올라간다.</p>
<p>코드비하인드 최소 연결이 필요하면 <code>EventToCommand</code>(툴킷 Behaviors)를 검토한다. 신규는 가능하면 <code>Command</code> 속성만 쓴다.</p>
<p>툴킷 없이 직접 구현하는 최소형:</p>
<pre><code class="hljs language-csharp"><span class="hljs-keyword">public</span> <span class="hljs-keyword">sealed</span> <span class="hljs-keyword">class</span> <span class="hljs-title">RelayCommand</span> : <span class="hljs-title">ICommand</span>
{
    <span class="hljs-keyword">private</span> <span class="hljs-keyword">readonly</span> Action _execute;
    <span class="hljs-keyword">private</span> <span class="hljs-keyword">readonly</span> Func&lt;<span class="hljs-built_in">bool</span>&gt;? _canExecute;

    <span class="hljs-function"><span class="hljs-keyword">public</span> <span class="hljs-title">RelayCommand</span>(<span class="hljs-params">Action execute, Func&lt;<span class="hljs-built_in">bool</span>&gt;? canExecute = <span class="hljs-literal">null</span></span>)</span>
    {
        _execute = execute;
        _canExecute = canExecute;
    }

    <span class="hljs-function"><span class="hljs-keyword">public</span> <span class="hljs-built_in">bool</span> <span class="hljs-title">CanExecute</span>(<span class="hljs-params"><span class="hljs-built_in">object</span>? parameter</span>)</span> =&gt; _canExecute?.Invoke() ?? <span class="hljs-literal">true</span>;
    <span class="hljs-function"><span class="hljs-keyword">public</span> <span class="hljs-keyword">void</span> <span class="hljs-title">Execute</span>(<span class="hljs-params"><span class="hljs-built_in">object</span>? parameter</span>)</span> =&gt; _execute();
    <span class="hljs-keyword">public</span> <span class="hljs-keyword">event</span> EventHandler? CanExecuteChanged;

    <span class="hljs-function"><span class="hljs-keyword">public</span> <span class="hljs-keyword">void</span> <span class="hljs-title">RaiseCanExecuteChanged</span>()</span> =&gt;
        CanExecuteChanged?.Invoke(<span class="hljs-keyword">this</span>, EventArgs.Empty);
}</code></pre>
<p>직접 구현이면 <code>Title</code> setter에서 <code>SaveCommand.RaiseCanExecuteChanged()</code>를 호출해야 버튼이 살아난다. 빼먹기 쉽다. 그래서 툴킷을 기본선으로 둔다.</p>
<hr>
<h2>5. 주의 / 흔한 실수</h2>
<ul>
<li><strong><code>Click</code>과 <code>Command</code>를 동시에.</strong> 두 번 실행되거나 한쪽이 무시된다. 하나만 둔다.</li>
<li><strong><code>CanExecute</code>를 바꿨는데 <code>CanExecuteChanged</code>를 안 올림.</strong> 버튼이 영원히 비활성이다. <code>[NotifyCanExecuteChangedFor]</code> 또는 <code>NotifyCanExecuteChanged()</code>.</li>
<li><strong><code>async void</code> 이벤트 핸들러에 저장.</strong> 예외가 삼켜진다. <code>[RelayCommand] Task</code>를 쓴다.</li>
<li><strong>명령에서 <code>MessageBox</code>.</strong> View 의존. 5편 대화상자 서비스.</li>
<li><strong><code>RelayCommand</code>를 프로퍼티 get마다 <code>new</code>.</strong> 바인딩이 매번 새 객체다. 필드에 한 번 만들거나 툴킷 생성 명령을 쓴다.</li>
</ul>
<hr>
<h2>정리</h2>
<p>WPF 액션의 기본은 이벤트 남발이 아니라 <strong>테스트 가능한 Command</strong>다.</p>
<ul>
<li>클릭 → <code>{Binding XxxCommand}</code></li>
<li>활성 → <code>CanExecute</code> + 속성 변경 시 재평가</li>
<li>행 인자 → <code>CommandParameter</code></li>
</ul>
<hr>
<h2>연습</h2>
<ol>
<li><code>Title</code>이 비어 있으면 저장 버튼이 비활성인지, 한 글자 입력 후 활성화되는지 확인한다.</li>
<li><code>ClearCommand</code>로 제목과 상태가 초기화되는지 확인한다.</li>
<li><code>Save</code>를 <code>async Task</code>로 바꾸고 저장 중 <code>Status</code>가 <code>저장 중</code>으로 보이는지 확인한다.</li>
</ol>
