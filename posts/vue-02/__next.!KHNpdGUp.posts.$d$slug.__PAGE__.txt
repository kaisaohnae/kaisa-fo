3:T35ec,<h1>ref와 reactive로 반응형 상태 다루기</h1>
<blockquote>
<p>요약: 값이 바뀌면 화면이 다시 그려지도록 ref로 상태를 두고, 계산 값과 감시 로직을 나눈다.</p>
</blockquote>
<hr>
<h2>1. 왜 반응형인가</h2>
<p>일반 변수 <code>let n = 0</code>은 값이 바뀌어도 화면이 모른다. Vue의 반응형은 <strong>값이 바뀌면 그 값을 쓰는 템플릿을 다시 그리게</strong> 만든다.</p>
<p>언제 무엇을 쓰는가.</p>
<table>
<thead>
<tr>
<th>상황</th>
<th>선택</th>
</tr>
</thead>
<tbody><tr>
<td>숫자, 문자열, 불리언, 한 객체 참조</td>
<td><code>ref</code></td>
</tr>
<tr>
<td>서로 붙어 다니는 필드 묶음</td>
<td><code>reactive</code> 또는 <code>ref({ ... })</code></td>
</tr>
<tr>
<td>다른 상태에서 계산만 하는 값</td>
<td><code>computed</code></td>
</tr>
<tr>
<td>값이 바뀔 때 API 호출 등</td>
<td><code>watch</code> / <code>watchEffect</code></td>
</tr>
</tbody></table>
<p>실무 기본선은 <strong>거의 모든 상태를 <code>ref</code>로 두고</strong>, 필드가 많은 폼만 <code>reactive</code>를 검토한다.</p>
<hr>
<h2>2. 핵심 개념</h2>
<table>
<thead>
<tr>
<th>API</th>
<th>한 줄</th>
</tr>
</thead>
<tbody><tr>
<td><code>ref</code></td>
<td>값이 바뀌면 화면을 다시 그릴 상자. script에서는 <code>.value</code></td>
</tr>
<tr>
<td><code>reactive</code></td>
<td>객체 전체에 Proxy를 씌운다. 프로퍼티는 바로 읽는다</td>
</tr>
<tr>
<td>언래핑</td>
<td>템플릿은 <code>ref</code> 상자를 자동으로 연다</td>
</tr>
<tr>
<td><code>computed</code></td>
<td>다른 상태에 의존하는 캐시된 파생 값</td>
</tr>
<tr>
<td><code>watch</code></td>
<td>특정 상자가 바뀔 때 부수 효과를 실행한다</td>
</tr>
</tbody></table>
<p><code>ref</code>로 객체를 담아도 된다. <code>user.value.name = &#39;a&#39;</code>처럼 연 뒤 필드를 바꾼다. Vue 3는 객체 <code>ref</code>의 안쪽도 반응형이다.</p>
<hr>

<h2>4. 구조 분해와 교체</h2>
<p><code>reactive</code> 객체를 구조 분해하면 반응형이 끊긴다.</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">const</span> form = <span class="hljs-title function_">reactive</span>({ <span class="hljs-attr">name</span>: <span class="hljs-string">&#x27;&#x27;</span>, <span class="hljs-attr">age</span>: <span class="hljs-number">0</span> })
<span class="hljs-keyword">const</span> { name } = form <span class="hljs-comment">// name은 일반 문자열. 이후 form.name 변경이 이 변수에 안 온다</span></code></pre>
<p>필드를 따로 쓰려면 <code>toRefs</code>를 쓴다.</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">import</span> { reactive, toRefs } <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;vue&#x27;</span>

<span class="hljs-keyword">const</span> form = <span class="hljs-title function_">reactive</span>({ <span class="hljs-attr">name</span>: <span class="hljs-string">&#x27;&#x27;</span>, <span class="hljs-attr">age</span>: <span class="hljs-number">0</span> })
<span class="hljs-keyword">const</span> { name, age } = <span class="hljs-title function_">toRefs</span>(form) <span class="hljs-comment">// name.value, age.value</span></code></pre>
<p>객체 통째 교체도 <code>reactive</code>의 약점이다.</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">let</span> state = <span class="hljs-title function_">reactive</span>({ <span class="hljs-attr">name</span>: <span class="hljs-string">&#x27;a&#x27;</span> })

<p>통째 교체가 필요하면 <code>ref</code>로 담는다.</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">const</span> state = <span class="hljs-title function_">ref</span>({ <span class="hljs-attr">name</span>: <span class="hljs-string">&#x27;a&#x27;</span> })

<p>화면 표시용 계산은 <code>computed</code>다. 저장 API, <code>localStorage</code>, 포커스 이동은 <code>watch</code>다.</p>
<hr>
<h2>6. 주의 / 흔한 실수</h2>
<ul>
<li><strong>script에서 <code>.value</code> 누락.</strong> <code>count = 1</code>은 <code>ref</code> 상자를 숫자로 덮어 반응형이 죽는다. <code>count.value = 1</code>이다.</li>
<li><strong><code>reactive</code>에 원시값.</strong> <code>reactive(0)</code>은 객체가 아니라서 기대한 추적이 안 된다. 원시는 <code>ref</code>.</li>
<li><strong><code>reactive</code> 변수 재할당.</strong> 위 4절. 교체가 필요하면 <code>ref</code>.</li>
<li><strong>deep <code>watch</code> 남용.</strong> <code>{ deep: true }</code>는 큰 객체에서 비용이 크다. 경로를 좁힌다.</li>
<li><strong><code>computed</code> 안에서 상태 변경.</strong> 파생만 한다. 쓰기는 <code>watch</code>나 이벤트 핸들러.</li>
</ul>
<hr>
<h2>정리</h2>
<p>상태를 만들 때 질문 하나는 이것이다. <strong>값 하나인가, 필드 묶음인가.</strong></p>
<ul>
<li>하나 → <code>ref</code></li>
<li>묶음 → <code>reactive</code> 또는 <code>ref({ ... })</code></li>
<li>파생 → <code>computed</code></li>
<li>부수 효과 → <code>watch</code></li>
</ul>
<p>거의 모든 신규 코드는 <code>ref</code>만으로도 충분하다.</p>
<hr>
<h2>연습</h2>
<ol>
<li><code>ref</code>로 <code>score</code>를 두고, <code>computed</code>로 60 이상이면 <code>통과</code> 아니면 <code>재시험</code>을 표시한다.</li>
<li><code>reactive</code> 주소 객체 <code>{ city, street }</code>를 만들고 <code>toRefs</code>로 템플릿에 나눠 바인딩한다.</li>
<li><code>watch</code>로 <code>score</code>가 100이 되면 <code>console.log(&#39;만점&#39;)</code>을 한 번 출력한다.</li>
</ol>
