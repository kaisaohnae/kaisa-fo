24:T39e9,<h1>컴포넌트 props·emits·슬롯</h1>
<blockquote>
<p>요약: 부모는 props로 값을 내리고 자식은 이벤트로 알리며, 슬롯으로 자리를 열어 컴포넌트를 조립한다.</p>
</blockquote>
<hr>
<h2>1. 왜 계약을 좁히는가</h2>
<p>화면을 한 파일에 두면 수정이 한곳에 몰린다. 카드·검색창·모달처럼 <strong>같은 UI를 여러 곳에서</strong> 쓸 때 컴포넌트로 나눈다.</p>
<p>데이터는 한 방향으로만 흐른다.</p>
<table>
<thead>
<tr>
<th>방향</th>
<th>이름</th>
<th>한 줄</th>
</tr>
</thead>
<tbody><tr>
<td>부모 → 자식</td>
<td>props</td>
<td>부모가 자식에게 내려주는 값. 자식은 읽기만 한다</td>
</tr>
<tr>
<td>자식 → 부모</td>
<td>emits</td>
<td>자식이 부모에게 보내는 알림. 값은 이벤트로 올린다</td>
</tr>
<tr>
<td>부모 → 자식 UI</td>
<td>slots</td>
<td>자식 템플릿의 구멍. 부모가 마크업을 채운다</td>
</tr>
</tbody></table>
<p>자식이 <code>props</code>를 직접 바꾸면 부모가 가진 진실과 어긋난다. 바꿀 일이 있으면 이벤트를 올려 부모가 상태를 고친다.</p>
<hr>
<h2>2. 핵심 문법 (script setup)</h2>
<p><code>&lt;script setup&gt;</code>에서는 컴파일러 매크로를 쓴다. import 하지 않는다.</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">const</span> props = defineProps&lt;{
  <span class="hljs-attr">title</span>: <span class="hljs-built_in">string</span>
  <span class="hljs-attr">count</span>?: <span class="hljs-built_in">number</span>
}&gt;()

<span class="hljs-keyword">const</span> emit = defineEmits&lt;{
  <span class="hljs-attr">select</span>: [<span class="hljs-attr">id</span>: <span class="hljs-built_in">string</span>]
  <span class="hljs-attr">close</span>: []
}&gt;()</code></pre>
<ul>
<li><code>title</code>은 필수, <code>count</code>는 선택</li>
<li><code>select</code>는 문자열 인자 하나, <code>close</code>는 인자 없음</li>
<li>매크로 결과는 런타임에 컴포넌트 옵션으로 옮겨진다</li>
</ul>
<p>Vue 3.5+에서는 <code>defineProps</code>에 기본값을 <code>withDefaults</code>로 붙인다.</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">const</span> props = <span class="hljs-title function_">withDefaults</span>(
  defineProps&lt;{ <span class="hljs-attr">title</span>: <span class="hljs-built_in">string</span>; <span class="hljs-attr">count</span>?: <span class="hljs-built_in">number</span> }&gt;(),
  { <span class="hljs-attr">count</span>: <span class="hljs-number">0</span> },
)</code></pre>

    @remove=&quot;onRemove&quot;
  &gt;
    &lt;<span class="hljs-keyword">template</span> #actions&gt;
      &lt;button <span class="hljs-keyword">type</span>=&quot;button&quot; @click=&quot;onSelect(user.id)&quot;&gt;이 사람 선택&lt;/button&gt;
    &lt;/<span class="hljs-keyword">template</span>&gt;
  &lt;/UserCard&gt;
&lt;/<span class="hljs-keyword">template</span>&gt;</code></pre>
<ul>
<li><code>:user=&quot;user&quot;</code> — props로 객체 전달</li>
<li><code>@select=&quot;onSelect&quot;</code> — emit 이름이 이벤트 이름</li>
<li><code>#actions</code> — named slot. 자식이 기본 버튼을 넣었고, 부모가 덮어쓴다</li>
<li><code>v-for</code>의 <code>key</code>는 안정적인 <code>id</code>. 인덱스는 목록이 줄면 잘못 재사용된다</li>
</ul>
<hr>
<h2>4. v-model과 defineModel</h2>
<p>검색창처럼 <strong>자식 입력이 부모 상태와 같아야</strong> 하면 <code>v-model</code>을 쓴다. 실제로는 props + emit 관례다.</p>
<p>부모:</p>
<pre><code class="hljs language-vue">&lt;SearchInput v-model<span class="hljs-operator">=</span><span class="hljs-string">&quot;query&quot;</span> /&gt;</code></pre>
<p>자식 (Vue 3.4+):</p>
<pre><code class="hljs language-vue"><span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">script</span> <span class="hljs-attr">setup</span> <span class="hljs-attr">lang</span>=<span class="hljs-string">&quot;ts&quot;</span>&gt;</span><span class="language-javascript">
<span class="hljs-keyword">const</span> model = defineModel&lt;string&gt;(</span></span><span class="hljs-template-variable">{ <span class="hljs-keyword">default</span>: &#x27;&#x27; }</span><span class="language-xml"><span class="language-javascript">)
</span><span class="hljs-tag">&lt;/<span class="hljs-name">script</span>&gt;</span>

<span class="hljs-tag">&lt;<span class="hljs-name">template</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">input</span> <span class="hljs-attr">:value</span>=<span class="hljs-string">&quot;model&quot;</span> @<span class="hljs-attr">input</span>=<span class="hljs-string">&quot;model = ($event.target as HTMLInputElement).value&quot;</span> /&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">template</span>&gt;</span></span></code></pre>
<p>축약:</p>
<pre><code class="hljs language-vue"><span class="hljs-tag">&lt;<span class="hljs-name">template</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">input</span> <span class="hljs-attr">v-model</span>=<span class="hljs-string">&quot;model&quot;</span> /&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">template</span>&gt;</span></code></pre>
<p><code>defineModel</code>은 <code>modelValue</code> props와 <code>update:modelValue</code> emit을 대신 만든다. 팀이 Vue 3.4 미만이면 수동으로 같은 계약을 적는다.</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">const</span> props = defineProps&lt;{ <span class="hljs-attr">modelValue</span>: <span class="hljs-built_in">string</span> }&gt;()
<span class="hljs-keyword">const</span> emit = defineEmits&lt;{ <span class="hljs-string">&#x27;update:modelValue&#x27;</span>: [<span class="hljs-attr">value</span>: <span class="hljs-built_in">string</span>] }&gt;()</code></pre>
<hr>
<h2>5. 슬롯 세 종류</h2>
<table>
<thead>
<tr>
<th>종류</th>
<th>용도</th>
</tr>
</thead>
<tbody><tr>
<td>default</td>
<td><code>&lt;slot&gt;</code> 한 곳. 태그 사이 내용</td>
</tr>
<tr>
<td>named</td>
<td><code>#header</code>, <code>#actions</code>처럼 구역을 나눔</td>
</tr>
<tr>
<td>scoped</td>
<td>자식이 슬롯에 데이터를 넘겨 부모가 마크업을 그림</td>
</tr>
</tbody></table>
<p>scoped 예:</p>
<pre><code class="hljs language-vue"><span class="language-xml"><span class="hljs-comment">&lt;!-- 자식 --&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">slot</span> <span class="hljs-attr">name</span>=<span class="hljs-string">&quot;item&quot;</span> <span class="hljs-attr">:row</span>=<span class="hljs-string">&quot;row&quot;</span> /&gt;</span>

<span class="hljs-comment">&lt;!-- 부모 --&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">template</span> #<span class="hljs-attr">item</span>=<span class="hljs-string">&quot;{ row }&quot;</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">strong</span>&gt;</span></span><span class="hljs-template-variable">{{ <span class="hljs-name">row.name</span> }}</span><span class="language-xml"><span class="hljs-tag">&lt;/<span class="hljs-name">strong</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">template</span>&gt;</span></span></code></pre>
<p>레이아웃·디자인 시스템에서 슬롯이 재사용의 핵심이다. props로 HTML을 넘기지 않는다.</p>
<hr>
<h2>6. 주의 / 흔한 실수</h2>
<ul>
<li><strong>자식에서 <code>props.user.name = &#39;x&#39;</code>.</strong> 단방향이 깨진다. emit으로 올리고 부모가 배열을 교체한다.</li>
<li><strong>이벤트 이름을 동사 없이.</strong> <code>select</code>, <code>remove</code>, <code>update:modelValue</code>처럼 의도를 적는다. <code>change</code>만 있으면 무엇이 변했는지 모른다.</li>
<li><strong>props 객체/배열을 자식이 <code>push</code>.</strong> 참조를 공유하므로 부모 상태를 몰래 바꾼다. 새 배열을 만들어 emit한다.</li>
<li><strong><code>v-for</code>에 <code>key</code> 없음.</strong> 슬롯·입력이 엉뚱한 행에 남는다.</li>
<li><strong>슬롯 대신 <code>v-html</code>로 부모 HTML 주입.</strong> XSS(크로스 사이트 스크립팅) 위험이 크다. 슬롯을 쓴다.</li>
</ul>
<hr>
<h2>정리</h2>
<p>컴포넌트 API는 기능 나열이 아니다. <strong>props / emits / slots 세 계약을 좁고 분명하게</strong> 적는 일이다.</p>
<ul>
<li>내려줄 값 → props (읽기 전용)</li>
<li>올릴 일 → emits</li>
<li>채울 UI → slots</li>
<li>입력 동기화 → <code>v-model</code> / <code>defineModel</code></li>
</ul>
<hr>
<h2>연습</h2>
<ol>
<li><code>AlertBanner.vue</code>에 <code>message: string</code> props와 <code>close</code> emit을 넣고, 부모가 닫으면 배너를 제거한다.</li>
<li><code>SearchInput.vue</code>에 <code>defineModel&lt;string&gt;()</code>을 연결해 부모 <code>query</code>와 양방향으로 맞춘다.</li>
<li>카드에 <code>#footer</code> named slot을 추가하고, 부모에서 수정 링크를 넣는다.</li>
</ol>
