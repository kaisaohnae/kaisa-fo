24:T31c3,<h1>Server Component와 Client Component</h1>
<blockquote>
<p>요약: 기본은 서버 컴포넌트로 두고, 클릭·입력처럼 브라우저가 필요한 부분만 Client로 나눈다.</p>
</blockquote>
<hr>
<h2>1. 왜 이 주제가 필요한가</h2>
<p>App Router의 컴포넌트는 기본이 <strong>RSC(React Server Component, 서버에서만 실행되는 컴포넌트)</strong> 다.</p>
<p>서버에서 돌면 DB·파일·비밀키에 바로 접근할 수 있다. 그 코드는 브라우저 번들에 안 실려서 JS가 줄어든다.</p>
<p>모든 파일을 <code>&#39;use client&#39;</code>로 열면 이 이점이 사라진다. 반대로 서버 파일에 <code>onClick</code>을 붙이면 빌드가 실패한다. 경계를 아는 것이 App Router의 핵심이다.</p>
<hr>
<h2>2. 한 줄 규칙</h2>
<p>데이터와 마크업은 서버에 둔다. <code>useState</code>·이벤트·브라우저 API가 필요한 잎만 Client로 만든다.</p>
<p>페이지 전체가 Client일 필요는 없다. Client가 Server를 import하면 그 트리도 클라이언트가 된다. 반대로 Server는 Client를 자식으로 둘 수 있다.</p>
<hr>

      <span class="hljs-tag">&lt;<span class="hljs-name">PostFilters</span> <span class="hljs-attr">titles</span>=<span class="hljs-string">{titles}</span> /&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">Counter</span> /&gt;</span>
    <span class="hljs-tag">&lt;/<span class="hljs-name">main</span>&gt;</span></span>
  );
}</code></pre>
<p>서버가 데이터를 가져와 <strong>직렬화 가능한 props</strong>(문자열, 숫자, 평범한 객체·배열)만 Client에 넘긴다.</p>
<p>넘기면 안 되는 것: 함수, Class 인스턴스, <code>Date</code>를 제외한 특수 객체. 함수를 props로 넘기면 직렬화 에러가 난다.</p>
<h3>공유 모듈이 경계를 오염시킨다</h3>
<p>Client 파일이 <code>lib/format.ts</code>를 import하면, 그 모듈은 클라이언트 번들에 들어간다. 그 <code>lib/format.ts</code>가 <code>fs</code>를 import하면 브라우저 빌드가 실패한다.</p>
<p>서버 전용 코드는 <code>server-only</code> 패키지로 표시할 수 있다.</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">import</span> <span class="hljs-string">&#x27;server-only&#x27;</span>;

<span class="hljs-keyword">export</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">loadSecret</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">return</span> process.<span class="hljs-property">env</span>.<span class="hljs-property">API_SECRET</span>;
}</code></pre>
<p>Client가 이 파일을 import하면 빌드 단계에서 막힌다.</p>
<h3>큰 라이브러리</h3>
<p>차트·에디터처럼 무거운 패키지는 그 UI를 쓰는 Client 파일에서만 import한다. 루트 레이아웃에 두면 모든 페이지 번들이 커진다.</p>
<p>브라우저 전용 라이브러리는 동적 import로 나눈다.</p>
<pre><code class="hljs language-tsx"><span class="hljs-string">&#x27;use client&#x27;</span>;

<span class="hljs-keyword">import</span> dynamic <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;next/dynamic&#x27;</span>;

<span class="hljs-keyword">const</span> <span class="hljs-title class_">Chart</span> = <span class="hljs-title function_">dynamic</span>(<span class="hljs-function">() =&gt;</span> <span class="hljs-keyword">import</span>(<span class="hljs-string">&#x27;./chart&#x27;</span>), {
  <span class="hljs-attr">ssr</span>: <span class="hljs-literal">false</span>,
  <span class="hljs-attr">loading</span>: <span class="hljs-function">() =&gt;</span> <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">p</span>&gt;</span>차트 로딩<span class="hljs-tag">&lt;/<span class="hljs-name">p</span>&gt;</span></span>,
});</code></pre>
<p><code>ssr: false</code>는 정말 브라우저에서만 돌아야 할 때만 쓴다. 남용하면 첫 HTML이 비어 검색·미리보기에 불리하다.</p>

<h2>정리</h2>
<p>기본은 Server다. Client는 상호작용이 있는 잎이다.</p>
<p>서버가 데이터를 가져오고, 직렬화 가능한 값만 Client에 넘긴다. 페이지를 Client로 여는 것은 최후의 수단이다.</p>
<hr>
<h2>연습</h2>
<ol>
<li>서버 페이지에서 글 목록을 읽고, Client 검색 입력으로 제목을 거른다.</li>
<li><code>&#39;use client&#39;</code>가 붙은 파일을 찾아, 상태·이벤트가 없는 파일은 지시어를 제거한다.</li>
<li><code>npm run build</code> 출력에서 큰 Client 번들이 들어간 라우트를 확인하고, 무거운 import를 해당 페이지로 옮긴다.</li>
</ol>
