3:T2c59,<h1>Observability — Actuator, Micrometer, OpenTelemetry</h1>
<blockquote>
<p>요약: Actuator와 OpenTelemetry로 헬스·메트릭·트레이스를 붙여, 느린 지점과 장애 지점을 관측한다.</p>
</blockquote>
<hr>
<h2>1. 왜 관측인가</h2>
<p><strong>Observability(관측 가능성)</strong> 는 로그·메트릭·트레이스만으로 “왜 느리고 어디서 깨졌는지”를 답할 수 있는 상태다.</p>
<table>
<thead>
<tr>
<th>기둥</th>
<th>질문</th>
</tr>
</thead>
<tbody><tr>
<td>Logs</td>
<td>무슨 일이 있었나</td>
</tr>
<tr>
<td>Metrics</td>
<td>얼마나, 얼마나 자주</td>
</tr>
<tr>
<td>Traces</td>
<td>이 요청의 시간이 어디에 쓰였나</td>
</tr>
</tbody></table>
<p>Boot 3는 <strong>Micrometer Observation API</strong>로 메트릭과 트레이스를 같은 계측에서 뽑는다. <strong>Micrometer</strong>는 벤더에 치우치지 않는 메트릭 파사드다.</p>
<hr>
<h2>2. Actuator</h2>
<p>한 줄 정의: <strong>Actuator</strong>는 헬스·메트릭·정보 같은 운영 엔드포인트를 HTTP로 연다.</p>

<p>운영에서는 별도 포트와 인증으로 막는다. <code>include: &#39;*&#39;</code>는 힙덤프까지 노출하기 쉽다.</p>
<hr>
<h2>3. Health Indicator</h2>
<p>외부 결제망처럼 앱이 떠 있어도 트래픽을 받으면 안 되는 의존성은 readiness에 넣을지 팀 정책으로 정한다. 헬스마다 외부 ping을 치면 헬스 자체가 장애가 된다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@Component</span>
<span class="hljs-keyword">public</span> <span class="hljs-keyword">class</span> <span class="hljs-title class_">PaymentGatewayHealthIndicator</span> <span class="hljs-keyword">implements</span> <span class="hljs-title class_">HealthIndicator</span> {

    <span class="hljs-keyword">private</span> <span class="hljs-keyword">final</span> PaymentClient client;

    <span class="hljs-type">public</span> <span class="hljs-title function_">PaymentGatewayHealthIndicator</span><span class="hljs-params">(PaymentClient client)</span> {
        <span class="hljs-built_in">this</span>.client = client;
    }

    <span class="hljs-meta">@Override</span>
    <span class="hljs-keyword">public</span> <span class="hljs-type">Health</span> <span class="hljs-title function_">health</span><span class="hljs-params">()</span> {
        <span class="hljs-keyword">try</span> {
            client.ping();
            <span class="hljs-keyword">return</span> Health.up().withDetail(<span class="hljs-string">&quot;payment&quot;</span>, <span class="hljs-string">&quot;reachable&quot;</span>).build();
        } <span class="hljs-keyword">catch</span> (Exception e) {
            <span class="hljs-keyword">return</span> Health.down(e).build();
        }
    }
}</code></pre>

<h2>4. 메트릭과 Observation</h2>
<p>Prometheus 레지스트리를 붙이면 <code>/actuator/prometheus</code>로 나간다.</p>
<pre><code class="hljs language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">dependency</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">groupId</span>&gt;</span>io.micrometer<span class="hljs-tag">&lt;/<span class="hljs-name">groupId</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">artifactId</span>&gt;</span>micrometer-registry-prometheus<span class="hljs-tag">&lt;/<span class="hljs-name">artifactId</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">dependency</span>&gt;</span></code></pre>
<p>HTTP 서버·<code>RestClient</code>·DataSource는 Boot가 기본 계측한다. 비즈니스 카운터는 직접 심는다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@Service</span>
<span class="hljs-keyword">public</span> <span class="hljs-keyword">class</span> <span class="hljs-title class_">CheckoutService</span> {

    <span class="hljs-keyword">private</span> <span class="hljs-keyword">final</span> Counter checkoutCounter;
    <span class="hljs-keyword">private</span> <span class="hljs-keyword">final</span> Timer checkoutTimer;

    <span class="hljs-type">public</span> <span class="hljs-title function_">CheckoutService</span><span class="hljs-params">(MeterRegistry registry)</span> {
        <span class="hljs-built_in">this</span>.checkoutCounter = registry.counter(<span class="hljs-string">&quot;checkout.completed&quot;</span>);
        <span class="hljs-built_in">this</span>.checkoutTimer = registry.timer(<span class="hljs-string">&quot;checkout.latency&quot;</span>);
    }

    <span class="hljs-keyword">public</span> <span class="hljs-type">void</span> <span class="hljs-title function_">checkout</span><span class="hljs-params">(Order order)</span> {
        checkoutTimer.record(() -&gt; {
            <span class="hljs-comment">// 유스케이스</span>
            checkoutCounter.increment();
        });
    }
}</code></pre>
<p>Observation은 메트릭과 트레이스를 한 구간으로 묶는다. 카디널리티가 높은 값(userId, 주문번호)을 태그로 넣으면 시계열이 폭발한다.</p>
<pre><code class="hljs language-java">Observation.createNotStarted(<span class="hljs-string">&quot;order.create&quot;</span>, observationRegistry)
        .lowCardinalityKeyValue(<span class="hljs-string">&quot;type&quot;</span>, <span class="hljs-string">&quot;online&quot;</span>)
        .observe(() -&gt; orderService.create(request));</code></pre>

<h2>5. OpenTelemetry</h2>
<p>한 줄 정의: <strong>OpenTelemetry(OTel)</strong> 는 트레이스·메트릭·로그를 보내는 공개 표준이다. Micrometer Tracing이 OTel 브리지로 스팬을 내보내고, Collector가 Jaeger·Tempo 등으로 넘긴다.</p>
<pre><code class="hljs language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">dependency</span>&gt;</span>

  <span class="hljs-tag">&lt;<span class="hljs-name">artifactId</span>&gt;</span>opentelemetry-exporter-otlp<span class="hljs-tag">&lt;/<span class="hljs-name">artifactId</span>&gt;</span>

<h2>6. 구조화 로그</h2>
<p>운영 로그는 JSON이 검색·알람에 유리하다. Logback encoder 또는 Log4j2 JSON layout을 쓴다.</p>
<p>남길 것: timestamp, level, service, env, traceId, spanId, 내부 userId, 제한된 스택.<br>남기지 말 것: 비밀번호, 토큰, 카드번호, 주민번호, 개인정보 원문.</p>
<hr>
<h2>7. 알람 최소선</h2>
<ul>
<li><code>http.server.requests</code> p99 급증</li>
<li><code>hikaricp.connections.pending</code>이 지속</li>
<li>5xx 비율</li>
<li>readiness 실패</li>
<li>JVM GC·힙, Tomcat 큐</li>
</ul>
<p>대시보드는 RED(Rate, Errors, Duration)와 의존성 지연, 그리고 <code>order.created</code> 같은 비즈니스 카운터를 같이 본다.</p>
