24:T2f39,<h1>애니메이션·제스처·사용자 경험</h1>
<blockquote>
<p>요약: Reanimated와 Gesture Handler로 터치 피드백을 만들고, 햅틱·접근성까지 맞춘다.</p>
</blockquote>
<hr>
<h2>1. 왜 Reanimated인가</h2>
<p>웹은 CSS transition과 메인 스레드가 가깝다. RN에서 <code>setState</code>로 매 프레임 위치를 바꾸면 JS 스레드가 막혀 터치가 늦다.</p>
<p>복잡한 제스처와 60fps 애니메이션은 <strong>react-native-reanimated</strong>와 <strong>react-native-gesture-handler</strong>가 표준이다. 값을 UI 스레드에서 읽는다. Expo 템플릿에 이미 들어 있는 경우가 많다.</p>
<p>모든 화면에 모션을 넣지 않는다. 누르기, 스와이프 삭제, 모달처럼 <strong>의미가 있는 피드백</strong>만 남긴다.</p>
<hr>
<h2>2. 핵심 개념</h2>
<ul>
<li><code>useSharedValue</code>: UI 스레드가 읽는 값</li>
<li><code>useAnimatedStyle</code>: 그 값 → 스타일</li>
<li><code>withSpring</code> / <code>withTiming</code>: 목표까지 보간</li>
<li>worklet: UI 스레드에서 도는 함수</li>
</ul>
<p>제스처는 <code>GestureDetector</code>에 제스처 객체를 넘긴다. <code>Pan</code>, <code>Pinch</code>, <code>Tap</code>을 <code>Simultaneous</code> / <code>Exclusive</code>로 조합한다.</p>
<p>레이아웃 애니메이션(<code>entering</code>/<code>exiting</code>)은 리스트 추가·삭제에 쓰면 이해가 된다. 매 화면 페이드는 피로하다.</p>
<p>Expo Router의 native stack 전환은 기본으로 충분하다. 커스텀 트랜지션은 필요할 때만.</p>
<p>OS “동작 줄이기”가 켜져 있으면 큰 애니메이션을 건너뛴다.</p>
<hr>

<p>모달 화면:</p>
<pre><code class="hljs language-tsx">&lt;<span class="hljs-title class_">Stack</span>.<span class="hljs-property">Screen</span> name=<span class="hljs-string">&quot;compose&quot;</span> options={{ <span class="hljs-attr">presentation</span>: <span class="hljs-string">&#x27;modal&#x27;</span> }} /&gt;</code></pre>
<p>약한 햅틱:</p>
<pre><code class="hljs language-bash">npx expo install expo-haptics</code></pre>
<pre><code class="hljs language-tsx"><span class="hljs-keyword">import</span> * <span class="hljs-keyword">as</span> <span class="hljs-title class_">Haptics</span> <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;expo-haptics&#x27;</span>;

<span class="hljs-keyword">await</span> <span class="hljs-title class_">Haptics</span>.<span class="hljs-title function_">impactAsync</span>(<span class="hljs-title class_">Haptics</span>.<span class="hljs-property">ImpactFeedbackStyle</span>.<span class="hljs-property">Light</span>);
<span class="hljs-keyword">await</span> <span class="hljs-title class_">Haptics</span>.<span class="hljs-title function_">notificationAsync</span>(<span class="hljs-title class_">Haptics</span>.<span class="hljs-property">NotificationFeedbackType</span>.<span class="hljs-property">Success</span>);</code></pre>
<p>성공·삭제·토글에만 쓴다. 스크롤마다 울리면 방해다.</p>
<p>로딩은 스피너보다 스켈레톤이 목록에서 체감이 낫다. mutation은 낙관적 업데이트 후 실패 시 롤백한다.</p>
<p>최소 피드백은 opacity만으로도 된다.</p>
<pre><code class="hljs language-tsx">style={<span class="hljs-function">(<span class="hljs-params">{ pressed }</span>) =&gt;</span> [{ <span class="hljs-attr">opacity</span>: pressed ? <span class="hljs-number">0.7</span> : <span class="hljs-number">1</span> }]}</code></pre>
<p>접근성: <code>accessibilityLabel</code>, 포커스 순서, 동작 줄이기.</p>

<h2>5. 정리</h2>
<p>모션은 장식이 아니라 <strong>터치가 먹혔다는 신호</strong>다. UI 스레드에서 돌리고, 접근성과 햅틱을 같이 본다.</p>
<ul>
<li>Reanimated + Gesture Handler가 기본 조합이다.</li>
