3:T308f,<h1>라우팅·레이아웃·동적 세그먼트</h1>
<blockquote>
<p>요약: 폴더가 URL이 되는 규칙을 익히고, 동적 주소와 중첩 레이아웃으로 화면 구조를 잡는다.</p>
</blockquote>
<hr>
<h2>1. 왜 이 주제가 필요한가</h2>
<p>웹 앱은 URL이 곧 정보 구조다. <code>/posts/hello</code>가 글이고 <code>/about</code>이 소개라면, 폴더를 그렇게 나누면 된다.</p>
<p>App Router는 설정 파일에 라우트를 나열하지 않는다. <code>app/</code> 아래 폴더 이름이 경로가 된다. 레이아웃은 부모 폴더에서 자식으로 중첩된다.</p>
<p>주소와 UI 껍질을 같이 설계하면 페이지마다 헤더를 복사하지 않아도 된다.</p>
<hr>
<h2>2. 한 줄 규칙</h2>
<p><code>page.tsx</code>가 있는 폴더만 공개 URL이다. 대괄호 폴더(<code>[slug]</code>)는 값이 바뀌는 구간이다.</p>
<p>레이아웃은 하위 이동 시 리마운트되지 않는다. 공통 셸은 <code>layout.tsx</code>에 둔다.</p>
<hr>
<h2>3. 예제</h2>

<p><code>[slug]</code>는 한 칸. <code>[...slug]</code>는 나머지 칸 전부(캐치올). <code>[[...slug]]</code>는 그 칸이 없어도 된다(선택 캐치올).</p>
<h3>동적 세그먼트</h3>
<p>Next.js 15부터 <code>params</code>는 Promise다. 서버 페이지에서 <code>await</code>로 읽는다.</p>
<pre><code class="hljs language-tsx"><span class="hljs-comment">// app/posts/[slug]/page.tsx</span>
<span class="hljs-keyword">import</span> {notFound} <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;next/navigation&#x27;</span>;

<span class="hljs-keyword">type</span> <span class="hljs-title class_">Props</span> = {
  <span class="hljs-attr">params</span>: <span class="hljs-title class_">Promise</span>&lt;{<span class="hljs-attr">slug</span>: <span class="hljs-built_in">string</span>}&gt;;
};

<span class="hljs-keyword">const</span> <span class="hljs-attr">POSTS</span>: <span class="hljs-title class_">Record</span>&lt;<span class="hljs-built_in">string</span>, <span class="hljs-built_in">string</span>&gt; = {
  <span class="hljs-attr">hello</span>: <span class="hljs-string">&#x27;첫 글&#x27;</span>,
  <span class="hljs-attr">world</span>: <span class="hljs-string">&#x27;둘째 글&#x27;</span>,
};

<span class="hljs-keyword">export</span> <span class="hljs-keyword">default</span> <span class="hljs-keyword">async</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">PostPage</span>(<span class="hljs-params">{params}: <span class="hljs-title class_">Props</span></span>) {
  <span class="hljs-keyword">const</span> {slug} = <span class="hljs-keyword">await</span> params;
  <span class="hljs-keyword">const</span> title = <span class="hljs-variable constant_">POSTS</span>[slug];
  <span class="hljs-keyword">if</span> (!title) <span class="hljs-title function_">notFound</span>();
  <span class="hljs-keyword">return</span> (
    <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">article</span>&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">h1</span>&gt;</span>{title}<span class="hljs-tag">&lt;/<span class="hljs-name">h1</span>&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">p</span>&gt;</span>slug: {slug}<span class="hljs-tag">&lt;/<span class="hljs-name">p</span>&gt;</span>
    <span class="hljs-tag">&lt;/<span class="hljs-name">article</span>&gt;</span></span>
  );
}</code></pre>
<p>빌드 때 HTML을 미리 만들려면 <code>generateStaticParams</code>를 같이 쓴다. 정적 사이트 생성(SSG, 빌드 시 HTML을 고정하는 방식)과 충돌하지 않는다. <code>await params</code>는 Next API일 뿐, 페이지를 클라이언트 렌더로 바꾸지 않는다.</p>
<pre><code class="hljs language-tsx"><span class="hljs-keyword">export</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">generateStaticParams</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">return</span> [{<span class="hljs-attr">slug</span>: <span class="hljs-string">&#x27;hello&#x27;</span>}, {<span class="hljs-attr">slug</span>: <span class="hljs-string">&#x27;world&#x27;</span>}];
}</code></pre>
<h3>중첩 레이아웃</h3>
<pre><code class="hljs language-tsx"><span class="hljs-comment">// app/posts/layout.tsx</span>
<span class="hljs-keyword">import</span> <span class="hljs-keyword">type</span> {<span class="hljs-title class_">ReactNode</span>} <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;react&#x27;</span>;
<span class="hljs-keyword">import</span> <span class="hljs-title class_">Link</span> <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;next/link&#x27;</span>;

<span class="hljs-keyword">export</span> <span class="hljs-keyword">default</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">PostsLayout</span>(<span class="hljs-params">{children}: {children: ReactNode}</span>) {
  <span class="hljs-keyword">return</span> (
    <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">div</span>&gt;</span>
      <span class="hljs-tag">&lt;<span class="hljs-name">aside</span>&gt;</span>
        <span class="hljs-tag">&lt;<span class="hljs-name">nav</span>&gt;</span>

        <span class="hljs-tag">&lt;/<span class="hljs-name">nav</span>&gt;</span>

  );
}</code></pre>
<p><code>/posts/hello</code>에서 <code>/posts/world</code>로 이동해도 이 레이아웃은 다시 마운트되지 않는다. 사이드바 스크롤·필터 상태를 유지하기 쉽다.</p>
<p>루트 <code>layout.tsx</code>는 <code>&lt;html&gt;</code>/<code>&lt;body&gt;</code>를 가진다. 하위 레이아웃은 그 안의 껍질만 추가한다.</p>
<h3>라우트 그룹</h3>
<p>폴더 이름을 <code>(marketing)</code>처럼 괄호로 감싸면 URL에 안 들어간다. 레이아웃만 나누고 싶을 때 쓴다.</p>
<pre><code class="hljs">app/<span class="hljs-punctuation">(</span>site<span class="hljs-punctuation">)</span>/page.tsx              → /
app/<span class="hljs-punctuation">(</span>site<span class="hljs-punctuation">)</span>/about/page.tsx        → /about
app/<span class="hljs-punctuation">(</span>manager<span class="hljs-punctuation">)</span>/manager/page.tsx   → /manager</code></pre>
<p><code>(site)</code>와 <code>(manager)</code>에 서로 다른 <code>layout.tsx</code>를 둘 수 있다. 주소는 폴더 이름에서 괄호 그룹을 뺀 나머지다.</p>
<h3>Link와 이동</h3>
<pre><code class="hljs language-tsx"><span class="hljs-keyword">import</span> <span class="hljs-title class_">Link</span> <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;next/link&#x27;</span>;

<span class="hljs-keyword">export</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">PostLink</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">return</span> <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">Link</span> <span class="hljs-attr">href</span>=<span class="hljs-string">&quot;/posts/hello/&quot;</span>&gt;</span>글 보기<span class="hljs-tag">&lt;/<span class="hljs-name">Link</span>&gt;</span></span>;
}</code></pre>
<p>내부 이동은 <code>&lt;a&gt;</code> 대신 <code>next/link</code>의 <code>Link</code>를 쓴다. 미리 코드를 받아 전환이 빠르다.</p>
<p><code>trailingSlash: true</code>면 <code>href</code>도 <code>/posts/hello/</code>처럼 맞춘다. 슬래시가 어긋나면 같은 페이지가 두 URL로 열린다.</p>
<p>버튼을 눌러 이동할 때는 Client Component에서 라우터를 쓴다.</p>
<pre><code class="hljs language-tsx"><span class="hljs-string">&#x27;use client&#x27;</span>;

<span class="hljs-keyword">import</span> {useRouter} <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;next/navigation&#x27;</span>;

<span class="hljs-keyword">export</span> <span class="hljs-keyword">function</span> <span class="hljs-title function_">GoPostsButton</span>(<span class="hljs-params"></span>) {
  <span class="hljs-keyword">const</span> router = <span class="hljs-title function_">useRouter</span>();
  <span class="hljs-keyword">return</span> (
    <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">button</span> <span class="hljs-attr">type</span>=<span class="hljs-string">&quot;button&quot;</span> <span class="hljs-attr">onClick</span>=<span class="hljs-string">{()</span> =&gt;</span> router.push(&#x27;/posts/&#x27;)}&gt;
      목록
    <span class="hljs-tag">&lt;/<span class="hljs-name">button</span>&gt;</span></span>
  );
}</code></pre>
<p><code>next/navigation</code>이다. Pages Router의 <code>next/router</code>가 아니다.</p>
<h3>병렬·인터셉트</h3>
<p><code>@folder</code> 슬롯은 한 레이아웃에 여러 <code>page</code>를 나란히 넣을 때 쓴다. 대시보드 다중 패널이 전형적인 경우다.</p>
<p><code>(.)photo</code> 같은 인터셉트 라우트는 목록 위에 모달을 얹고, 새로고침하면 전용 페이지로 열 때 쓴다.</p>
<p>입문 앱은 동적 세그먼트와 중첩 레이아웃만으로 충분한 경우가 많다. 필요할 때 문서에서 추가한다.</p>

<h2>정리</h2>
<p>라우팅은 폴더 이름이고, 공개 여부는 <code>page.tsx</code>다. 바뀌는 칸은 <code>[slug]</code>, 공통 셸은 <code>layout.tsx</code>다.</p>
<p>URL을 먼저 그리고 폴더를 만든다. 레이아웃은 “이 구간에서 무엇이 유지돼야 하는가”로 나눈다.</p>
<hr>
<h2>연습</h2>
<ol>
<li><code>/posts/[slug]</code> 페이지와 <code>generateStaticParams</code> 두 개(<code>hello</code>, <code>world</code>)를 만든다.</li>
<li><code>(marketing)</code> / <code>(app)</code> 그룹으로 공개 사이트와 로그인 후 화면의 레이아웃을 나눈다.</li>
<li>내부 링크를 모두 <code>Link</code>로 바꾸고, <code>trailingSlash</code> 정책과 <code>href</code>를 맞춘다.</li>
</ol>
