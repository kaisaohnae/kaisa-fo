24:T34a3,<h1>컴포넌트·스타일·레이아웃 — Flex와 StyleSheet</h1>
<blockquote>
<p>요약: View·Text·StyleSheet와 Flexbox로 화면을 배치하고, 웹 CSS와 다른 점을 기준으로 레이아웃을 익힌다.</p>
</blockquote>
<hr>
<h2>1. 왜 StyleSheet인가</h2>
<p>웹은 HTML + CSS다. React Native는 <strong>컴포넌트 + 스타일 객체</strong>다. 선택자, 캐스케이드, 클래스 조합이 없다.</p>
<p>그래서 레이아웃은 Flexbox가 전부라고 봐도 된다. 그리드는 기본이 아니다. <code>display: block</code>도 없다. 모든 <code>View</code>가 이미 flex 컨테이너다.</p>
<p>이 차이를 먼저 고정해야 카드, 헤더, 하단 버튼이 기대한 자리에 간다.</p>
<hr>
<h2>2. 핵심 개념</h2>
<table>
<thead>
<tr>

<p>문자열은 반드시 <code>Text</code> 안에 둔다. <code>View</code> 직하 텍스트는 에러다.</p>
<p>웹 CSS와 다른 점:</p>
<ul>
<li>단위는 <strong>dp</strong>(밀도 독립 픽셀). <code>px</code> 문자열을 쓰지 않는다. 숫자만 넣는다.</li>
<li>기본 <code>flexDirection</code>은 <strong><code>column</code></strong>. 웹의 <code>row</code>가 아니다.</li>
<li>스타일 상속은 거의 없다. <code>Text</code>가 부모 <code>Text</code>를 일부 물려받는 정도다.</li>
<li>배열로 합친다: <code>style={[styles.card, compact &amp;&amp; styles.compact]}</code>.</li>
</ul>
<p>화면 가장자리(노치, 홈 인디케이터)는 <code>SafeAreaView</code>로 피한다. <code>react-native-safe-area-context</code>가 사실상 필수다.</p>
<hr>

<h2>5. 정리</h2>
<p>RN 레이아웃은 CSS를 옮긴 것이 아니다. <strong>숫자 단위 + column Flex + StyleSheet 배열</strong>이 기본 문법이다.</p>
<ul>
<li><code>View</code>/<code>Text</code>/<code>Pressable</code>만으로 대부분의 화면을 만든다.</li>
<li>화면 가득은 조상부터 <code>flex: 1</code>.</li>
<li>플랫폼 차이는 <code>Platform.select</code>. 색은 토큰.</li>
</ul>
<h2>연습</h2>
<ol>
<li>이미지·제목·가격·버튼이 있는 카드를 Flex로 만든다.</li>
<li><code>SafeAreaView</code>로 헤더 / 본문 / 하단 CTA를 나눈다.</li>
<li>iOS·Android 그림자를 <code>Platform.select</code>로 맞춘다.</li>
<li><code>expo-image</code>로 원격 이미지를 표시한다.</li>
