3:T2b3f,<h1>Spring Boot 3와 Java 21 시작하기</h1>
<blockquote>
<p>요약: Java 21과 Spring Boot 3.x로 프로젝트를 세팅하고, 자동 구성·프로파일·record 같은 기본선을 잡는다.</p>
</blockquote>
<hr>
<h2>1. 왜 지금 Spring Boot인가</h2>
<p>Spring Boot는 <strong>관례 기반(Convention over Configuration)</strong> 으로 기동한다. 자주 쓰는 기능은 starter 의존성으로 붙이고, 나머지는 기본값을 따른다.</p>
<p>Boot 3의 전제:</p>
<table>
<thead>
<tr>
<th>항목</th>
<th>Boot 2.x</th>
<th>Boot 3.x</th>
</tr>
</thead>
<tbody><tr>
<td>Java</td>
<td>8+</td>
<td><strong>17 필수, 21이 실무 기본선</strong></td>
</tr>
<tr>
<td>패키지</td>
<td><code>javax.*</code></td>
<td><strong><code>jakarta.*</code></strong></td>
</tr>
<tr>
<td>서블릿</td>
<td>4</td>
<td>5/6</td>
</tr>
<tr>
<td>Native</td>
<td>실험</td>
<td>GraalVM Native 정식</td>
</tr>
<tr>
<td>관측</td>
<td>Micrometer 1.x</td>
<td>Observation API + OpenTelemetry</td>
</tr>
</tbody></table>
<p>Jakarta는 Java EE가 Eclipse 재단으로 옮기며 패키지 이름이 바뀐 것이다. Boot 3 코드와 의존성은 <code>jakarta.validation</code>, <code>jakarta.persistence</code>처럼 <strong><code>jakarta.*</code>만</strong> 쓴다.</p>
<p>실무 기본선은 <strong>Java 21 LTS + Spring Boot 3.4+</strong> 다.</p>
<hr>
<h2>2. 프로젝트 생성</h2>
<p><a href="https://start.spring.io">start.spring.io</a>에서 Java 21, Jar, 최신 3.x를 고른다. 최소 의존성은 Spring Web, Validation, Actuator면 충분하다. JPA·DB 드라이버는 영속성이 필요할 때 추가한다.</p>
<pre><code class="hljs language-bash">curl https://start.spring.io/starter.zip \
  -d <span class="hljs-built_in">type</span>=maven-project \
  -d language=java \
  -d bootVersion=3.4.5 \
  -d javaVersion=21 \
  -d dependencies=web,validation,actuator \
  -o demo.zip</code></pre>
<p>Lombok은 팀 합의 후에만 넣는다. record와 생성자 주입이면 없어도 된다.</p>
<hr>
<h2>3. 디렉터리</h2>
<p>패키지를 <code>controller/service/repository</code>로만 나누면 기능이 커질수록 파일이 흩어진다. <strong>도메인과 어댑터</strong>를 기준으로 두는 편이 유지보수에 유리하다.</p>
<pre><code class="hljs">src<span class="hljs-operator">/</span>main<span class="hljs-operator">/</span>java<span class="hljs-operator">/</span>com<span class="hljs-operator">/</span>example<span class="hljs-operator">/</span>demo<span class="hljs-symbol">/</span>
├── DemoApplication.java
├── config<span class="hljs-symbol">/</span>
├── domain<span class="hljs-symbol">/</span>
├── application<span class="hljs-symbol">/</span>
├── adapter<span class="hljs-operator">/</span>web<span class="hljs-symbol">/</span>
├── adapter<span class="hljs-operator">/</span>persistence<span class="hljs-symbol">/</span>
└── common<span class="hljs-symbol">/</span>
src<span class="hljs-operator">/</span>main<span class="hljs-operator">/</span>resources<span class="hljs-symbol">/</span>
├── application.yml

├── application-prod.yml
└── db<span class="hljs-operator">/</span>migration<span class="hljs-operator">/</span></code></pre>
<hr>
<h2>4. <code>@SpringBootApplication</code></h2>
<p>한 줄 정의: <strong>설정 클래스 + 자동 구성 + 컴포넌트 스캔</strong>을 한 어노테이션으로 묶은 진입점이다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@SpringBootApplication</span>
<span class="hljs-keyword">public</span> <span class="hljs-keyword">class</span> <span class="hljs-title class_">DemoApplication</span> {
    <span class="hljs-keyword">public</span> <span class="hljs-keyword">static</span> <span class="hljs-type">void</span> <span class="hljs-title function_">main</span><span class="hljs-params">(String[] args)</span> {
        SpringApplication.run(DemoApplication.class, args);
    }
}</code></pre>
<ul>
<li><code>@SpringBootConfiguration</code> — 이 클래스가 설정이다</li>
<li><code>@EnableAutoConfiguration</code> — classpath에 있는 starter를 조건에 맞게 켠다</li>
<li><code>@ComponentScan</code> — 이 패키지 이하만 스캔한다</li>
</ul>
<p>자동 구성 목록은 <code>META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports</code>에 있다. 메인 클래스를 <code>com.example.demo</code> 밖에 두면 스캔 범위가 비는 것이 흔한 실수다.</p>
<hr>
<h2>5. <code>application.yml</code></h2>
<p>설정은 YAML + 프로파일 + 환경변수로 나눈다. 시크릿은 파일에 넣지 않는다.</p>
<pre><code class="hljs language-yaml"><span class="hljs-attr">spring:</span>
  <span class="hljs-attr">application:</span>
    <span class="hljs-attr">name:</span> <span class="hljs-string">demo</span>
  <span class="hljs-attr">profiles:</span>
    <span class="hljs-attr">active:</span> <span class="hljs-string">local</span>

<span class="hljs-attr">server:</span>
  <span class="hljs-attr">port:</span> <span class="hljs-number">8080</span>

<span class="hljs-attr">management:</span>
  <span class="hljs-attr">endpoints:</span>
    <span class="hljs-attr">web:</span>
      <span class="hljs-attr">exposure:</span>
        <span class="hljs-attr">include:</span> <span class="hljs-string">health,info</span>
  <span class="hljs-attr">endpoint:</span>
    <span class="hljs-attr">health:</span>
      <span class="hljs-attr">probes:</span>
        <span class="hljs-attr">enabled:</span> <span class="hljs-literal">true</span>

<span class="hljs-attr">logging:</span>

    <span class="hljs-attr">root:</span> <span class="hljs-string">INFO</span>

<p>Actuator는 운영 상태(헬스·메트릭)를 HTTP로 노출하는 모듈이다. 로컬에서 <code>health</code>만 열고, 운영 노출 범위는 나중에 줄인다.</p>

<h2>6. Java 21에서 바로 쓰는 문법</h2>
<h3>Record</h3>
<p>DTO·설정값처럼 <strong>불변 데이터</strong>에 맞다. getter·<code>equals</code>를 직접 만들지 않는다.</p>
<pre><code class="hljs language-java"><span class="hljs-keyword">public</span> <span class="hljs-keyword">record</span> <span class="hljs-title class_">CreateUserRequest</span><span class="hljs-params">(String email, String name)</span> {}
<span class="hljs-keyword">public</span> <span class="hljs-keyword">record</span> <span class="hljs-title class_">UserResponse</span><span class="hljs-params">(Long id, String email, String name)</span> {}</code></pre>
<h3>Sealed + pattern matching</h3>
<p>결과가 몇 가지로 닫혀 있으면 컴파일러가 분기를 검사한다.</p>
<pre><code class="hljs language-java"><span class="hljs-keyword">public</span> <span class="hljs-keyword">sealed</span> <span class="hljs-keyword">interface</span> <span class="hljs-title class_">PaymentResult</span>
        <span class="hljs-keyword">permits</span> PaymentResult.Success, PaymentResult.Failed {
    <span class="hljs-keyword">record</span> <span class="hljs-title class_">Success</span><span class="hljs-params">(String transactionId)</span> <span class="hljs-keyword">implements</span> <span class="hljs-title class_">PaymentResult</span> {}
    <span class="hljs-keyword">record</span> <span class="hljs-title class_">Failed</span><span class="hljs-params">(String reason)</span> <span class="hljs-keyword">implements</span> <span class="hljs-title class_">PaymentResult</span> {}
}

<span class="hljs-type">String</span> <span class="hljs-variable">message</span> <span class="hljs-operator">=</span> <span class="hljs-keyword">switch</span> (result) {
    <span class="hljs-keyword">case</span> PaymentResult.Success s -&gt; <span class="hljs-string">&quot;OK: &quot;</span> + s.transactionId();
    <span class="hljs-keyword">case</span> PaymentResult.Failed f -&gt; <span class="hljs-string">&quot;FAIL: &quot;</span> + f.reason();
};</code></pre>
<h3>Virtual Threads</h3>
<p>한 줄 정의: OS 스레드에 1:1로 묶이지 않는 <strong>가벼운 스레드</strong>로, JDBC·HTTP처럼 기다리는 I/O 비용을 낮춘다.</p>
<pre><code class="hljs language-yaml"><span class="hljs-attr">spring:</span>
  <span class="hljs-attr">threads:</span>
    <span class="hljs-attr">virtual:</span>
      <span class="hljs-attr">enabled:</span> <span class="hljs-literal">true</span></code></pre>
<p>Boot 3.2+에서 Tomcat 요청 처리에 붙는다. CPU 연산이 병목인 작업은 기적이 없고, DB 커넥션 풀 한도는 그대로다.</p>

curl http://localhost:8080/api/hello</code></pre>
