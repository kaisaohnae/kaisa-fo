3:T32b7,<h1>Blade·Livewire·Inertia와 API 프론트 전략</h1>
<blockquote>
<p>요약: Blade·Livewire·Inertia·순수 API 중 제품에 맞는 프론트를 고르고, 한 앱 안에서도 경계를 나누면 된다.</p>
</blockquote>
<hr>
<h2>1. “전부 React”가 기본값은 아니다</h2>
<p>프론트 선택은 팀 취향보다 <strong>누가 화면을 소유하는지</strong>에 가깝다. Laravel이 HTML을 그리면 검증·인가·라우트가 한곳에 남는다. 별도 SPA면 그 계약을 API로 문서화해야 한다.</p>
<table>
<thead>
<tr>
<th>상황</th>
<th>추천</th>
</tr>
</thead>
<tbody><tr>
<td>관리자·내부툴·폼이 많음</td>
<td>Filament 또는 Blade/Livewire</td>
</tr>
<tr>
<td>멀티페이지, SEO</td>
<td><strong>Blade</strong> (+ 필요한 곳만 JS)</td>
</tr>
<tr>
<td>SPA UX인데 Laravel 라우트·검증을 유지</td>
<td><strong>Inertia</strong> (Vue/React/Svelte)</td>
</tr>
<tr>
<td>모바일 앱과 웹이 따로</td>
<td>Sanctum API + 별도 프론트</td>

<p>한 제품에 마케팅은 Blade, 앱은 Inertia, 어드민은 Filament여도 된다. 경계를 URL이나 레이아웃으로 명확히 한다.</p>
<hr>
<h2>2. Blade</h2>
<p><strong>Blade</strong>는 Laravel 서버가 HTML을 조립하는 템플릿이다. <code>{{ $var }}</code>는 이스케이프되어 XSS를 줄인다. <code>{!! $html !!}</code>는 신뢰한 HTML만 넣는다. 사용자 입력을 그대로 <code>{!! !!}</code>에 넣으면 스크립트가 실행된다.</p>

<hr>
<h2>3. Vite</h2>
<p>자산 파이프라인의 기본은 <strong>Vite</strong>다. Mix는 레거시다.</p>
<pre><code class="hljs language-blade"><span class="hljs-meta">@vite([<span class="hljs-string">&#x27;resources/css/app.css&#x27;</span>, <span class="hljs-string">&#x27;resources/js/app.js&#x27;</span>])</span></code></pre>
<pre><code class="hljs language-bash">npm install
npm run dev
npm run build</code></pre>
<p>운영에서 <code>npm run build</code>를 빼면 CSS가 없거나 <code>@vite</code>가 개발 서버를 찾다 실패한다. 배포 스크립트에 포함한다.</p>
<hr>
<h2>4. Livewire</h2>
<p><strong>Livewire</strong>는 PHP 컴포넌트 상태로 화면을 부분 갱신한다. 검색 박스처럼 AJAX를 직접 짜기 싫은 CRUD·필터·위자드에 맞다. 오프라인 앱이나 캔버스급 인터랙션에는 맞지 않다.</p>
<pre><code class="hljs language-bash">composer require livewire/livewire
php artisan make:livewire PostSearch</code></pre>
<pre><code class="hljs language-php"><span class="hljs-class"><span class="hljs-keyword">class</span> <span class="hljs-title">PostSearch</span> <span class="hljs-keyword">extends</span> <span class="hljs-title">Component</span>

<p>Livewire 3의 islands·Volt는 팀 스타일에 맞게 선택한다. 필수는 아니다.</p>
<hr>
<h2>5. Inertia</h2>
<p><strong>Inertia</strong>는 서버가 JSON 대신 <strong>페이지 컴포넌트 이름 + props</strong>를 내려 주고, 프론트가 그 페이지를 그리는 방식이다. REST API를 하나 더 운영하는 SPA가 아니다. 라우팅·세션·Form Request 검증은 Laravel이 유지한다.</p>
<pre><code class="hljs language-bash">php artisan breeze:install vue</code></pre>
<pre><code class="hljs language-php"><span class="hljs-keyword">return</span> <span class="hljs-title class_">Inertia</span>::<span class="hljs-title function_ invoke__">render</span>(<span class="hljs-string">&#x27;Posts/Show&#x27;</span>, [
    <span class="hljs-string">&#x27;post&#x27;</span> =&gt; <span class="hljs-keyword">new</span> <span class="hljs-title class_">PostResource</span>(<span class="hljs-variable">$post</span>),
]);</code></pre>
<p>폼은 Inertia 헬퍼가 검증 에러를 공유 props로 돌려준다. API Resource를 props에 쓰면 JSON API와 필드 이름을 맞출 수 있다.</p>
<pre><code class="hljs language-js"><span class="hljs-keyword">import</span> { useForm } <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;@inertiajs/vue3&#x27;</span>

<span class="hljs-keyword">const</span> form = <span class="hljs-title function_">useForm</span>({ <span class="hljs-attr">title</span>: <span class="hljs-string">&#x27;&#x27;</span>, <span class="hljs-attr">body</span>: <span class="hljs-string">&#x27;&#x27;</span> })
form.<span class="hljs-title function_">post</span>(<span class="hljs-string">&#x27;/posts&#x27;</span>)</code></pre>
<p>모바일 앱이 같은 백엔드를 쓰면 Inertia만으로는 부족하다. 그때는 4~5편의 API + Sanctum을 따로 연다.</p>
<hr>
<h2>6. 순수 API + SPA</h2>
<p>Next.js·Nuxt 등 프론트가 완전히 분리되면:</p>
<ul>
<li>Form Request</li>
<li>API Resource</li>
<li>Sanctum (쿠키 또는 토큰)</li>
<li>OpenAPI (scribe / scramble)</li>
</ul>
<p>CORS, 쿠키 도메인, <code>/api/v1</code> 버전을 계약으로 적는다. Inertia와 순수 API를 한 컨트롤러에서 섞으면 응답 형태가 흔들린다. 진입점을 나눈다.</p>
<hr>
<h2>7. 실시간과 어드민</h2>
<p><strong>Reverb</strong>는 Laravel 공식 WebSocket 서버다. Echo가 브라우저에서 채널을 구독한다. 알림 벨, 대시보드 숫자 갱신에 쓴다. 채팅 전체를 Reverb만으로 만들기 전에 규모를 본다.</p>
<pre><code class="hljs language-bash">composer require laravel/reverb
php artisan reverb:install</code></pre>
<pre><code class="hljs language-php"><span class="hljs-title function_ invoke__">broadcast</span>(<span class="hljs-keyword">new</span> <span class="hljs-title class_">OrderStatusUpdated</span>(<span class="hljs-variable">$order</span>))-&gt;<span class="hljs-title function_ invoke__">toOthers</span>();</code></pre>
<p><strong>Filament</strong>는 관리자 CRUD·필터·권한을 리소스 기반으로 빨리 만든다. 고객용 UI와 관리자 UI를 한 Blade 트리에 섞지 않을 때 생산성이 크다. 패널 가드와 Policy를 고객 가드와 분리한다.</p>
<pre><code class="hljs language-bash">composer require filament/filament
php artisan filament:install --panels</code></pre>
<hr>
<h2>8. 조합 예</h2>
<ol>
<li>마케팅 사이트: Blade + Vite</li>
<li>SaaS 본편: Inertia + Fortify/Breeze + Policy</li>
<li>내부 어드민: Filament</li>
<li>모바일: Sanctum API</li>
<li>일부 위젯: Livewire 또는 Echo</li>
</ol>
<hr>
<h2>9. 흔한 실수</h2>
<ul>
<li>사용자 HTML을 <code>{!! !!}</code>에 넣는다.</li>
<li>Livewire public 프로퍼티로 가격·역할을 받는다.</li>
<li>Inertia와 JSON API를 한 액션에서 분기하다 계약이 갈라진다.</li>
<li><code>npm run build</code> 없이 배포한다.</li>
<li>어드민을 고객 <code>web</code> 가드에 그대로 연다.</li>
</ul>
<hr>
<h2>연습</h2>
<ol>
<li>Blade 컴포넌트로 플래시 알림을 만든다.</li>
<li>Livewire 검색 리스트 <strong>또는</strong> Inertia 상세 페이지 하나를 연결한다.</li>
<li>상세 데이터는 <code>PostResource</code> 형태로 내려 준다.</li>
<li>(선택) Reverb로 알림 이벤트 하나를 방송한다.</li>
</ol>
