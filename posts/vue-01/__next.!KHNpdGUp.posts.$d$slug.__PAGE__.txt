3:T2bb3,<h1>Vue 3 Composition API로 시작하기</h1>
<blockquote>
<p>요약: 한 파일에 화면·로직·스타일을 두고, script setup으로 Vue 3 컴포넌트를 시작한다.</p>
</blockquote>
<hr>
<h2>1. 언제 Vue 3인가</h2>
<p>Vue는 HTML 템플릿에 상태를 연결해 화면을 그리는 프레임워크다. 값이 바뀌면 해당 부분만 다시 그린다.</p>
<p>신규 프로젝트는 <strong>Vue 3 + TypeScript + <code>&lt;script setup&gt;</code></strong> 을 기본선으로 둔다. Vue 2는 유지보수만 한다.</p>
<table>
<thead>
<tr>
<th>항목</th>
<th>Vue 2</th>
<th>Vue 3</th>
</tr>
</thead>
<tbody><tr>
<td>기본 API</td>
<td>Options (<code>data</code>, <code>methods</code>)</td>
<td>Composition (<code>setup</code>, <code>ref</code>)</td>
</tr>
<tr>
<td>반응형</td>
<td><code>Object.defineProperty</code></td>
<td>Proxy</td>
</tr>
<tr>
<td>파일</td>
<td>Options SFC</td>
<td>SFC(단일 파일 컴포넌트) + script setup</td>
</tr>
<tr>
<td>TypeScript</td>
<td>보조</td>
<td>공식 경로</td>
</tr>

<p>Composition API(조합형 API)는 관련 코드를 함수 단위로 모아 재사용하기 쉽게 만든 방식이다. Options는 <code>data</code>/<code>methods</code>/<code>computed</code>로 역할이 갈라져, 한 기능이 파일 여러 곳에 흩어진다.</p>
<hr>
<h2>2. 핵심 구조</h2>
<p>SFC는 한 파일에 로직·마크업·스타일을 담는다.</p>
<pre><code class="hljs">Counter.vue
├── <span class="hljs-attribute">&lt;script setup&gt;</span>   상태와 동작
├── <span class="hljs-attribute">&lt;template&gt;</span>       화면
└── <span class="hljs-attribute">&lt;style scoped&gt;</span>   이 컴포넌트만의 스타일</code></pre>
<table>
<thead>
<tr>
<th>개념</th>
<th>한 줄</th>
</tr>
</thead>
<tbody><tr>
<td><code>createApp</code></td>
<td>앱을 만들고 <code>#app</code>에 붙인다</td>
</tr>
<tr>
<td>SFC</td>
<td><code>.vue</code> 한 장이 컴포넌트 하나다</td>
</tr>
<tr>
<td><code>&lt;script setup&gt;</code></td>
<td>setup의 축약. 최상위 변수·함수가 템플릿에 노출된다</td>
</tr>
<tr>
<td><code>scoped</code></td>
<td>스타일이 이 파일 밖으로 새지 않는다</td>
</tr>
</tbody></table>
<p>파일명은 <code>UserCard.vue</code>처럼 PascalCase로 둔다.</p>
<hr>
<h2>3. 프로젝트 생성</h2>
<pre><code class="hljs language-bash">npm create vue@latest my-app
<span class="hljs-built_in">cd</span> my-app
npm install
npm run dev</code></pre>
<p>선택 시 TypeScript, Vue Router, Pinia는 이후 글에서 다룬다. 지금은 Vue + TS만으로도 충분하다.</p>
<p>진입점은 <code>main.ts</code>다.</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">import</span> { createApp } <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;vue&#x27;</span>

<p><code>ref(0)</code>은 <strong>값이 바뀌면 화면을 다시 그릴 상자</strong>다. script에서는 <code>count.value</code>로 열고, 템플릿에서는 <code>{{ count }}</code>로 쓴다. Vue가 템플릿에서 상자를 자동으로 연다(언래핑).</p>
<p><code>&lt;script setup&gt;</code>은 <code>setup()</code> 함수의 문법 설탕이다. <code>export</code> 없이 선언한 이름만 템플릿이 본다.</p>
<hr>
<h2>5. Options와 무엇을 다르게 쓰는가</h2>
<p>Options API 예:</p>
<pre><code class="hljs language-vue"><span class="hljs-tag">&lt;<span class="hljs-name">script</span> <span class="hljs-attr">lang</span>=<span class="hljs-string">&quot;ts&quot;</span>&gt;</span><span class="language-javascript">
<span class="hljs-keyword">export</span> <span class="hljs-keyword">default</span> {
  <span class="hljs-title function_">data</span>(<span class="hljs-params"></span>) {
    <span class="hljs-keyword">return</span> { <span class="hljs-attr">count</span>: <span class="hljs-number">0</span> }
  },
  <span class="hljs-attr">methods</span>: {
    <span class="hljs-title function_">increment</span>(<span class="hljs-params"></span>) {
      <span class="hljs-variable language_">this</span>.<span class="hljs-property">count</span> += <span class="hljs-number">1</span>
    },
  },
}
</span><span class="hljs-tag">&lt;/<span class="hljs-name">script</span>&gt;</span></code></pre>
<p>동작은 같다. 다만 기능이 커지면 <code>data</code>와 <code>methods</code>가 멀어진다. Composition은 카운터 관련 코드를 한 블록에 둔다. 기존 Options 코드는 점진 이관하면 된다. 신규는 script setup만 쓴다.</p>
<hr>
<h2>6. 주의 / 흔한 실수</h2>
<ul>
<li><strong>Vue 2 문법으로 시작하기.</strong> <code>new Vue()</code>는 Vue 3가 아니다. <code>createApp</code>을 쓴다.</li>
<li><strong>script에서 <code>count</code>만 쓰기.</strong> <code>ref</code>는 <code>.value</code>가 실제 값이다. <code>count++</code>는 상자를 증가시키지 않는다.</li>
<li><strong><code>&lt;script setup&gt;</code>과 <code>export default</code>를 섞기.</strong> setup 블록은 컴포넌트 옵션 객체가 아니다.</li>
<li><strong>전역 CSS로 컴포넌트 스타일 잡기.</strong> <code>scoped</code>를 기본으로 둔다. 테마만 전역에 둔다.</li>
<li><strong>한 SFC에 화면 여러 개를 넣기.</strong> 파일 하나 = 책임 하나.</li>
</ul>
<hr>
<h2>정리</h2>
<p>Vue 3 시작은 버전 비교가 아니다. <strong>SFC + <code>&lt;script setup&gt;</code> + <code>ref</code></strong> 세 가지를 고정하면 나머지는 이 위에 쌓인다.</p>
<ul>
<li>화면 조각 → <code>.vue</code> 파일</li>
<li>변하는 값 → <code>ref</code> / <code>computed</code></li>
<li>앱 시작 → <code>createApp(App).mount(&#39;#app&#39;)</code></li>
</ul>
<hr>
<h2>연습</h2>
<ol>
<li><code>npm create vue@latest</code>로 프로젝트를 만들고 <code>Counter.vue</code>를 붙여 증가·초기화가 동작하는지 확인한다.</li>
<li><code>label</code> computed를 바꿔 10 이상이면 문구를 <code>많음</code>으로 표시한다.</li>
<li><code>HelloName.vue</code>를 만들어 입력한 이름을 <code>&lt;p&gt;</code>에 출력한다. 상태는 <code>ref(&#39;&#39;)</code> 하나로 둔다.</li>
</ol>
