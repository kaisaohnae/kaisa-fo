3:T2788,<h1>컴포넌트·템플릿·데이터 바인딩</h1>
<blockquote>
<p>요약: 템플릿에 값을 넣고 클릭을 받으며, @if/@for와 input/output으로 화면과 클래스를 연결한다.</p>
</blockquote>
<hr>
<h2>1. 왜 바인딩인가</h2>
<p>템플릿은 HTML처럼 보이지만 <strong>클래스 필드를 화면에 붙인 계약</strong>이다. 클래스가 진실이고, 템플릿은 표시와 클릭만 담당한다.</p>
<p>언제 어떤 문법을 쓰는가.</p>
<table>
<thead>
<tr>
<th>문법</th>
<th>방향</th>
<th>용도</th>
</tr>
</thead>
<tbody><tr>
<td><code>{{ expr }}</code></td>
<td>클래스 → 뷰</td>
<td>텍스트</td>
</tr>
<tr>
<td><code>[attr]</code> / <code>[prop]</code></td>
<td>클래스 → DOM·자식</td>
<td>disabled, src, 자식 input</td>
</tr>
<tr>
<td><code>(event)</code></td>
<td>뷰 → 클래스</td>
<td>click, submit, 자식 output</td>
</tr>
<tr>
<td><code>[(ngModel)]</code></td>
<td>양방향</td>
<td>작은 폼. <code>FormsModule</code> 필요</td>
</tr>
</tbody></table>
<p>복잡한 검증은 4편 Reactive Forms를 쓴다. 여기서는 표시·클릭·자식 계약만 고정한다.</p>
<hr>
<h2>2. 핵심 개념</h2>
<table>
<thead>
<tr>
<th>개념</th>
<th>한 줄</th>
</tr>
</thead>
<tbody><tr>
<td>인터폴레이션</td>
<td><code>{{ title }}</code> — 값을 텍스트로 넣는다</td>
</tr>
<tr>
<td>프로퍼티 바인딩</td>
<td><code>[disabled]=&quot;loading&quot;</code> — DOM 속성/프로퍼티에 연결한다</td>
</tr>
<tr>
<td>이벤트 바인딩</td>
<td><code>(click)=&quot;save()&quot;</code> — 브라우저 이벤트에 메서드를 붙인다</td>
</tr>
<tr>
<td><code>@if</code> / <code>@for</code></td>
<td>내장 제어 흐름. <code>*ngIf</code> / <code>*ngFor</code> 대신 신규 기본</td>
</tr>
<tr>
<td><code>input()</code></td>
<td>부모가 내려주는 값. 시그널이라 읽을 때 <code>name()</code></td>
</tr>
<tr>
<td><code>output()</code></td>
<td>자식이 부모에게 보내는 이벤트</td>
</tr>
</tbody></table>
<p><code>track</code>은 리스트에서 <strong>같은 행을 DOM에 재사용하기 위한 id</strong>다. 없으면 배열이 바뀔 때마다 행을 다시 만든다.</p>
<hr>
<h2>3. 동작하는 예: 목록과 카드</h2>
<p><code>src/app/user-card/user-card.ts</code>:</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">import</span> { <span class="hljs-title class_">Component</span>, input, output } <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;@angular/core&#x27;</span>;

<span class="hljs-meta">@Component</span>({
  <span class="hljs-attr">selector</span>: <span class="hljs-string">&#x27;app-user-card&#x27;</span>,
  <span class="hljs-attr">standalone</span>: <span class="hljs-literal">true</span>,
  <span class="hljs-attr">template</span>: <span class="hljs-string">`
    &lt;article&gt;
      &lt;p&gt;{{ name() }}&lt;/p&gt;
      &lt;button type=&quot;button&quot; (click)=&quot;select.emit(name())&quot;&gt;선택&lt;/button&gt;
    &lt;/article&gt;
  `</span>,
})
<span class="hljs-keyword">export</span> <span class="hljs-keyword">class</span> <span class="hljs-title class_">UserCard</span> {
  name = input.<span class="hljs-property">required</span>&lt;<span class="hljs-built_in">string</span>&gt;();
  select = output&lt;<span class="hljs-built_in">string</span>&gt;();
}</code></pre>
<p><code>input.required</code>는 부모가 값을 안 주면 컴파일·런타임에서 드러난다. <code>name()</code>은 시그널을 <strong>호출해 현재 값</strong>을 읽는다. <code>name</code>만 쓰면 시그널 함수 자체가 나온다.</p>
<p><code>src/app/home/home.ts</code>:</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">import</span> { <span class="hljs-title class_">Component</span> } <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;@angular/core&#x27;</span>;
<span class="hljs-keyword">import</span> { <span class="hljs-title class_">UserCard</span> } <span class="hljs-keyword">from</span> <span class="hljs-string">&#x27;../user-card/user-card&#x27;</span>;

<span class="hljs-keyword">type</span> <span class="hljs-title class_">User</span> = { <span class="hljs-attr">id</span>: <span class="hljs-built_in">string</span>; <span class="hljs-attr">name</span>: <span class="hljs-built_in">string</span> };

<span class="hljs-meta">@Component</span>({
  <span class="hljs-attr">selector</span>: <span class="hljs-string">&#x27;app-home&#x27;</span>,
  <span class="hljs-attr">standalone</span>: <span class="hljs-literal">true</span>,
  <span class="hljs-attr">imports</span>: [<span class="hljs-title class_">UserCard</span>],
  <span class="hljs-attr">template</span>: <span class="hljs-string">`
    &lt;button type=&quot;button&quot; [disabled]=&quot;loading&quot; (click)=&quot;reload()&quot;&gt;
      {{ loading ? &#x27;불러오는 중&#x27; : &#x27;다시 불러오기&#x27; }}
    &lt;/button&gt;

    @if (selected) {
      &lt;p&gt;선택: {{ selected }}&lt;/p&gt;
    } @else {
      &lt;p&gt;아직 선택 없음&lt;/p&gt;
    }

    &lt;ul&gt;
      @for (user of users; track user.id) {
        &lt;li&gt;
          &lt;app-user-card [name]=&quot;user.name&quot; (select)=&quot;onSelect($event)&quot; /&gt;
        &lt;/li&gt;
      } @empty {
        &lt;li&gt;사용자 없음&lt;/li&gt;
      }
    &lt;/ul&gt;
  `</span>,
})
<span class="hljs-keyword">export</span> <span class="hljs-keyword">class</span> <span class="hljs-title class_">Home</span> {
  loading = <span class="hljs-literal">false</span>;
  <span class="hljs-attr">selected</span>: <span class="hljs-built_in">string</span> | <span class="hljs-literal">null</span> = <span class="hljs-literal">null</span>;
  <span class="hljs-attr">users</span>: <span class="hljs-title class_">User</span>[] = [
    { <span class="hljs-attr">id</span>: <span class="hljs-string">&#x27;1&#x27;</span>, <span class="hljs-attr">name</span>: <span class="hljs-string">&#x27;김하늘&#x27;</span> },
    { <span class="hljs-attr">id</span>: <span class="hljs-string">&#x27;2&#x27;</span>, <span class="hljs-attr">name</span>: <span class="hljs-string">&#x27;이준&#x27;</span> },
  ];

  <span class="hljs-title function_">reload</span>(<span class="hljs-params"></span>) {
    <span class="hljs-variable language_">this</span>.<span class="hljs-property">loading</span> = <span class="hljs-literal">true</span>;
    <span class="hljs-variable language_">this</span>.<span class="hljs-property">loading</span> = <span class="hljs-literal">false</span>;
  }

  <span class="hljs-title function_">onSelect</span>(<span class="hljs-params"><span class="hljs-attr">name</span>: <span class="hljs-built_in">string</span></span>) {
    <span class="hljs-variable language_">this</span>.<span class="hljs-property">selected</span> = name;
  }
}</code></pre>
<ul>
<li><code>[name]=&quot;user.name&quot;</code> — 자식 input에 문자열을 넣는다</li>
<li><code>(select)=&quot;onSelect($event)&quot;</code> — <code>$event</code>가 <code>output</code>으로 내보낸 값</li>
<li><code>@empty</code> — 배열이 비었을 때 <code>@for</code> 전용 분기</li>
</ul>
<p><code>UserCard</code>를 템플릿에서 쓰려면 부모 <code>imports</code>에 넣는다. standalone의 핵심이다.</p>
<hr>
<h2>4. 옛 문법과의 대응</h2>
<table>
<thead>
<tr>
<th>신규</th>
<th>옛</th>
</tr>
</thead>
<tbody><tr>
<td><code>@if (user) { }</code></td>
<td><code>*ngIf=&quot;user&quot;</code></td>
</tr>
<tr>
<td><code>@for (x of xs; track x.id)</code></td>
<td><code>*ngFor=&quot;let x of xs; trackBy: trackId&quot;</code></td>
</tr>
<tr>
<td><code>name = input.required&lt;string&gt;()</code></td>
<td><code>@Input() name!: string</code></td>
</tr>
<tr>
<td><code>select = output&lt;string&gt;()</code></td>
<td><code>@Output() select = new EventEmitter&lt;string&gt;()</code></td>
</tr>
</tbody></table>
<p>옛 문법도 동작한다. 신규 화면은 내장 제어 흐름과 <code>input()</code>/<code>output()</code>을 쓴다. 한 파일에 둘을 섞지 않는 편이 읽기 쉽다.</p>
<p><code>[(ngModel)]</code>은 <code>FormsModule</code>을 <code>imports</code>에 넣어야 한다. 필드가 늘면 Reactive Forms로 옮긴다.</p>
<hr>
<h2>5. 주의 / 흔한 실수</h2>
<ul>
<li><strong>템플릿에서 <code>name</code>만 출력.</strong> 시그널 input은 <code>name()</code>이다. 안 부르면 <code>[object Function]</code>에 가깝게 보인다.</li>
<li><strong><code>track</code> 생략.</strong> 큰 목록에서 행 상태가 엉킨다. <code>track $index</code>는 최후 수단이다.</li>
<li><strong>템플릿에 구독·필터 로직 남발.</strong> <code>users.filter(...)</code>를 템플릿에 두면 변경 감지마다 새 배열이 생긴다. 클래스의 <code>computed</code>나 메서드 캐시를 쓴다.</li>
<li><strong><code>[innerHTML]</code>에 사용자 입력.</strong> XSS다. 텍스트는 <code>{{ }}</code>다.</li>
<li><strong><code>ChangeDetectionStrategy.OnPush</code>만 켜고 객체를 mutate.</strong> OnPush는 참조가 바뀌거나 시그널이 갱신될 때 잘 맞는다. 배열 <code>push</code>만으로는 화면이 안 바뀔 수 있다.</li>
</ul>
<hr>
<h2>정리</h2>
<p>템플릿은 뷰의 계약이다. <strong>표시는 바인딩, 분기는 @if/@for, 부모·자식은 input/output</strong>으로 좁힌다.</p>
<ul>
<li>텍스트·속성 → <code>{{ }}</code> / <code>[ ]</code></li>
<li>클릭 → <code>(click)</code></li>
<li>목록 → <code>@for</code> + <code>track</code></li>
<li>내려주기·올리기 → <code>input()</code> / <code>output()</code></li>
</ul>
<hr>
<h2>연습</h2>
<ol>
<li><code>loading</code>이 true일 때 버튼 문구와 <code>disabled</code>가 함께 바뀌는지 확인한다.</li>
<li><code>users</code>에 항목을 추가·삭제하는 버튼을 넣고 <code>@empty</code>가 보이는지 확인한다.</li>
<li><code>UserCard</code>에 <code>role = input&lt;string&gt;(&#39;일반&#39;)</code>을 추가하고 부모에서 한 명만 다른 role을 넘긴다.</li>
</ol>
