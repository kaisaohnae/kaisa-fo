3:T2a60,<h1>캐시·Redis·성능 최적화</h1>
<blockquote>
<p>요약: 느린 쿼리를 먼저 고친 뒤 Redis 캐시를 쓰고, 무효화 지점을 정해 두지 않으면 캐시는 낡은 화면이 된다.</p>
</blockquote>
<hr>
<h2>1. 최적화 순서</h2>
<p>캐시는 느린 증상을 가릴 수 있지만, N+1을 캐시하면 <strong>틀린 결과가 더 빨리</strong> 나간다. 순서를 지킨다.</p>
<ol>
<li>느린 쿼리·N+1 제거 (3편)</li>
<li>메일·리사이즈는 큐로 (7편)</li>
<li>읽기 많은 결과를 캐시</li>
<li>HTTP 캐시·CDN</li>
<li>필요할 때만 Octane·스케일 아웃</li>
</ol>
<p><code>Cache::remember</code>를 모든 메서드에 뿌리면 <strong>무효화</strong>(언제 지울지)를 아무도 모른다.</p>
<hr>
<h2>2. Redis와 드라이버</h2>
<p><strong>Redis</strong>는 메모리 키-값 저장소다. Laravel에서는 캐시, 세션, 큐, 속도 제한, 분산 락에 같은 인스턴스를 쓰는 경우가 많다. 용도별로 DB 번호를 나누거나, 트래픽이 커지면 인스턴스를 분리한다.</p>
<pre><code class="hljs language-env"><span class="hljs-attr">CACHE_STORE</span><span class="hljs-operator">=</span>redis
<span class="hljs-attr">REDIS_CLIENT</span><span class="hljs-operator">=</span>phpredis</code></pre>
<table>
<thead>
<tr>
<th>드라이버</th>
<th>언제</th>
</tr>
</thead>
<tbody><tr>
<td><code>array</code></td>
<td>요청 안만. 테스트</td>
</tr>
<tr>
<td><code>database</code> / <code>file</code></td>
<td>작은 단일 서버</td>
</tr>
<tr>
<td><code>redis</code></td>
<td>실무 기본</td>
</tr>
</tbody></table>
<p>파일 캐시는 여러 웹 서버에서 공유되지 않는다. 스케일 아웃하면 Redis(또는 Memcached)가 맞다.</p>
<hr>
<h2>3. 기본 API</h2>
<pre><code class="hljs language-php"><span class="hljs-variable">$post</span> = <span class="hljs-title class_">Cache</span>::<span class="hljs-title function_ invoke__">remember</span>(<span class="hljs-string">&#x27;posts.&#x27;</span>.<span class="hljs-variable">$id</span>, <span class="hljs-title function_ invoke__">now</span>()-&gt;<span class="hljs-title function_ invoke__">addMinutes</span>(<span class="hljs-number">10</span>), function () <span class="hljs-keyword">use</span> ($<span class="hljs-title">id</span>) {
    <span class="hljs-title">return</span> <span class="hljs-title">Post</span>::<span class="hljs-title">with</span>(&#x27;<span class="hljs-title">user</span>&#x27;)-&gt;<span class="hljs-title">findOrFail</span>($<span class="hljs-title">id</span>);
});

<span class="hljs-title class_">Cache</span>::<span class="hljs-title function_ invoke__">put</span>(<span class="hljs-string">&#x27;key&#x27;</span>, <span class="hljs-variable">$value</span>, <span class="hljs-number">600</span>);
<span class="hljs-title class_">Cache</span>::<span class="hljs-title function_ invoke__">forget</span>(<span class="hljs-string">&#x27;posts.&#x27;</span>.<span class="hljs-variable">$id</span>);
<span class="hljs-title class_">Cache</span>::<span class="hljs-title function_ invoke__">flush</span>(); <span class="hljs-comment">// 운영에서 전부 삭제 — 거의 쓰지 않는다</span></code></pre>
<p><code>remember</code>는 키가 있으면 반환하고, 없으면 클로저를 실행해 저장한다. TTL(수명) 없는 <code>forever</code>는 무효화를 반드시 코드로 해야 한다.</p>
<p>태그(Redis/Memcached)로 게시글 묶음을 한 번에 지운다.</p>
<pre><code class="hljs language-php"><span class="hljs-title class_">Cache</span>::<span class="hljs-title function_ invoke__">tags</span>([<span class="hljs-string">&#x27;posts&#x27;</span>, <span class="hljs-string">&#x27;user:&#x27;</span>.<span class="hljs-variable">$userId</span>])-&gt;<span class="hljs-title function_ invoke__">put</span>(<span class="hljs-variable">$key</span>, <span class="hljs-variable">$value</span>, <span class="hljs-number">600</span>);
<span class="hljs-title class_">Cache</span>::<span class="hljs-title function_ invoke__">tags</span>([<span class="hljs-string">&#x27;posts&#x27;</span>])-&gt;<span class="hljs-title function_ invoke__">flush</span>();</code></pre>
<p>database 드라이버는 태그를 지원하지 않는다. 로컬은 database, 운영은 Redis면 태그 코드가 운영에서만 동작한다. 드라이버를 맞춘다.</p>
<p>갱신은 Observer 한곳에 모은다. 컨트롤러마다 <code>forget</code>을 흩뿌리면 빠뜨린다.</p>
<pre><code class="hljs language-php"><span class="hljs-keyword">public</span> <span class="hljs-function"><span class="hljs-keyword">function</span> <span class="hljs-title">updated</span>(<span class="hljs-params">Post <span class="hljs-variable">$post</span></span>): <span class="hljs-title">void</span>
</span>{
    <span class="hljs-title class_">Cache</span>::<span class="hljs-title function_ invoke__">forget</span>(<span class="hljs-string">&#x27;posts.&#x27;</span>.<span class="hljs-variable">$post</span>-&gt;id);
    <span class="hljs-title class_">Cache</span>::<span class="hljs-title function_ invoke__">tags</span>([<span class="hljs-string">&#x27;posts&#x27;</span>])-&gt;<span class="hljs-title function_ invoke__">flush</span>();
}</code></pre>
<p>목록을 <code>posts.published.page.&#39;.$page</code>로 캐시하면 페이지마다 키가 는다. 글 하나 수정에 태그 flush가 없으면 목록이 하루 종일 옛날이다.</p>
<hr>
<h2>4. 프레임워크 캐시 (운영)</h2>
<p>설정·라우트·뷰를 PHP 파일로 묶어 부팅을 줄인다. <strong>배포 파이프라인</strong>에서 돌리고, 로컬에서 <code>route:cache</code>를 켜 두면 새 라우트가 안 보인다.</p>
<pre><code class="hljs language-bash">php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache</code></pre>
<p><code>config:cache</code> 뒤에 코드의 <code>env()</code>가 비는 문제는 1편과 같다.</p>
<hr>
<h2>5. HTTP 캐시</h2>
<pre><code class="hljs language-php"><span class="hljs-keyword">return</span> <span class="hljs-title function_ invoke__">response</span>(<span class="hljs-variable">$content</span>)
    -&gt;<span class="hljs-title function_ invoke__">header</span>(<span class="hljs-string">&#x27;Cache-Control&#x27;</span>, <span class="hljs-string">&#x27;public, max-age=60&#x27;</span>)
    -&gt;<span class="hljs-title function_ invoke__">setEtag</span>(<span class="hljs-title function_ invoke__">md5</span>(<span class="hljs-variable">$content</span>));</code></pre>
<p><code>public</code>은 CDN·공유 캐시가 응답을 저장해도 된다는 뜻이다. <strong>로그인 사용자마다 다른 JSON</strong>에 <code>public</code>을 붙이면 남의 이름이 캐시에 남는다. 개인화는 <code>private</code> 또는 캐시하지 않는다.</p>
<hr>
<h2>6. 락</h2>
<p>같은 주문에 결제 요청이 두 번 들어오면 Redis 락으로 임계 구역을 좁힌다. 락은 DB 유니크 제약을 대체하지 않는다. 둘 다 쓰는 편이 안전하다.</p>
<pre><code class="hljs language-php"><span class="hljs-variable">$lock</span> = <span class="hljs-title class_">Cache</span>::<span class="hljs-title function_ invoke__">lock</span>(<span class="hljs-string">&#x27;order:&#x27;</span>.<span class="hljs-variable">$orderId</span>, <span class="hljs-number">10</span>);

<span class="hljs-keyword">if</span> (<span class="hljs-variable">$lock</span>-&gt;<span class="hljs-title function_ invoke__">get</span>()) {
    <span class="hljs-keyword">try</span> {
        <span class="hljs-comment">// 한 번에 하나만</span>
    } <span class="hljs-keyword">finally</span> {
        <span class="hljs-variable">$lock</span>-&gt;<span class="hljs-title function_ invoke__">release</span>();
    }
}</code></pre>
<p>락을 못 받으면 빈 200을 주면 클라이언트가 성공으로 오해한다. 409나 재시도 안내를 정한다.</p>
<hr>
<h2>7. 쿼리가 여전히 먼저다</h2>
<ul>
<li><code>preventLazyLoading</code>으로 N+1을 로컬에서 터뜨린다.</li>
<li><code>select</code>로 필요한 컬럼만. <code>with([&#39;user:id,name&#39;])</code>처럼 제한한다.</li>
<li><code>where</code>/<code>orderBy</code>에 인덱스, 의심되면 <code>EXPLAIN</code>.</li>
<li>대량은 <code>chunkById</code> / <code>lazyById</code>.</li>
</ul>
<pre><code class="hljs language-php"><span class="hljs-title class_">Post</span>::<span class="hljs-title function_ invoke__">with</span>([
    <span class="hljs-string">&#x27;user:id,name&#x27;</span>,
    <span class="hljs-string">&#x27;tags:id,name&#x27;</span>,
    <span class="hljs-string">&#x27;comments&#x27;</span> =&gt; fn (<span class="hljs-variable">$q</span>) =&gt; <span class="hljs-variable">$q</span>-&gt;<span class="hljs-title function_ invoke__">latest</span>()-&gt;<span class="hljs-title function_ invoke__">limit</span>(<span class="hljs-number">5</span>),
])-&gt;<span class="hljs-title function_ invoke__">get</span>();</code></pre>
<p>Debugbar·Telescope는 로컬/스테이징용이다. 요청당 쿼리 개수를 숫자로 본다. 감으로 “Redis 넣자”보다 쿼리 20번이 원인인 경우가 많다.</p>
<hr>
<h2>8. Octane은 선택</h2>
<p><strong>Octane</strong>은 Swoole/RoadRunner로 앱을 메모리에 상주시켜, 요청마다 프레임워크를 다시 켜는 비용을 줄인다. 트래픽이 크고 부트 비용이 CPU를 잡아먹을 때 이득이다.</p>
<p>주의: static이나 싱글톤에 요청 데이터를 남기면 <strong>다음 사용자에게 유출</strong>된다. 일반 PHP-FPM에서는 요청이 끝나면 사라지던 습관이 Octane에서는 남는다. 도입 전에 상태 오염을 점검하고, 배포 시 워커 리로드 전략이 필요하다.</p>
<pre><code class="hljs language-bash">composer require laravel/octane
php artisan octane:install</code></pre>
<hr>
<h2>9. 흔한 실수</h2>
<ul>
<li>측정 없이 전부 <code>remember</code>한다.</li>
<li><code>Cache::flush()</code>로 세션·다른 앱 키까지 지운다.</li>
<li>개인화 응답에 <code>Cache-Control: public</code>.</li>
<li>수정 시 <code>forget</code>을 빼먹어 관리자가 “저장했는데 안 바뀐다”고 한다.</li>
<li>Redis 없이 태그 캐시를 전제한다.</li>
</ul>
<p>측정은 p95 지연, 요청당 쿼리 수, Redis hit 비율, 큐 대기 시간을 같이 본다. Telescope는 운영 전면 공개 금지.</p>
<hr>
<h2>연습</h2>
<ol>
<li>게시글 상세를 <code>remember</code>하고, 수정 Observer에서 <code>forget</code>한다.</li>
<li>Redis lock으로 중복 결제 요청을 거절한다.</li>
<li>스테이징에서 <code>config:cache</code> / <code>route:cache</code> 후 앱이 뜨는지 확인한다.</li>
<li>목록 API 쿼리 수를 <code>with</code> 전후로 비교한다.</li>
</ol>
