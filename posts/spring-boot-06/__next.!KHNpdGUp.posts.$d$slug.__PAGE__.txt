3:T2ec0,<h1>테스트 — JUnit 5, MockMvc, Testcontainers</h1>
<blockquote>
<p>요약: 단위·슬라이스·통합 테스트 비중을 나누고, Testcontainers로 실제 DB에 가까운 검증을 한다.</p>
</blockquote>
<hr>
<h2>1. 왜 피라미드를 나누는가</h2>
<p>모든 케이스를 <code>@SpringBootTest</code>로 올리면 CI가 느리고 실패 지점이 흐려진다. 빠른 테스트로 규칙을 지키고, 조립은 소수 통합으로 확인한다.</p>
<table>
<thead>
<tr>
<th>종류</th>
<th>도구</th>
<th>목적</th>
</tr>
</thead>
<tbody><tr>
<td>단위</td>
<td>JUnit + Mockito</td>
<td>도메인·서비스 규칙</td>
</tr>
<tr>
<td>슬라이스</td>
<td><code>@WebMvcTest</code>, <code>@DataJpaTest</code></td>
<td>계층 경계</td>
</tr>
<tr>
<td>통합</td>
<td><code>@SpringBootTest</code> + Testcontainers</td>
<td>실제 조립</td>
</tr>
<tr>
<td>E2E</td>
<td>RestAssured 등</td>
<td>핵심 시나리오만</td>
</tr>
</tbody></table>
<p><strong>슬라이스 테스트</strong>는 웹 또는 JPA처럼 <strong>한 계층만</strong> 띄우는 테스트다.</p>
<hr>
<h2>2. 단위 테스트</h2>
<p>Spring 컨텍스트 없이 생성자로 목을 넣는다.</p>
<pre><code class="hljs language-java"><span class="hljs-keyword">class</span> <span class="hljs-title class_">OrderServiceTest</span> {

    <span class="hljs-meta">@Test</span>
    <span class="hljs-type">void</span> <span class="hljs-title function_">rejectsEmptyItems</span><span class="hljs-params">()</span> {
        <span class="hljs-type">OrderRepository</span> <span class="hljs-variable">repo</span> <span class="hljs-operator">=</span> mock(OrderRepository.class);
        <span class="hljs-type">OrderService</span> <span class="hljs-variable">service</span> <span class="hljs-operator">=</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">OrderService</span>(repo);

        assertThatThrownBy(() -&gt; service.create(<span class="hljs-keyword">new</span> <span class="hljs-title class_">CreateOrderRequest</span>(List.of())))
                .isInstanceOf(InvalidOrderException.class);
    }
}</code></pre>
<p>필드 <code>@Autowired</code> 서비스는 이런 테스트가 불편해진다.</p>
<hr>
<h2>3. <code>@WebMvcTest</code></h2>
<p>컨트롤러·검증·예외 핸들러만 올린다. 서비스는 목이다. Boot 3.4+는 <code>@MockitoBean</code>(<code>@MockBean</code> 후속)을 쓴다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@WebMvcTest(UserController.class)</span>
<span class="hljs-meta">@Import(GlobalExceptionHandler.class)</span>
<span class="hljs-keyword">class</span> <span class="hljs-title class_">UserControllerTest</span> {

    <span class="hljs-meta">@Autowired</span> MockMvc mockMvc;
    <span class="hljs-meta">@MockitoBean</span> UserService userService;

    <span class="hljs-meta">@Test</span>
    <span class="hljs-type">void</span> <span class="hljs-title function_">createUser</span><span class="hljs-params">()</span> <span class="hljs-keyword">throws</span> Exception {
        given(userService.create(any()))
                .willReturn(<span class="hljs-keyword">new</span> <span class="hljs-title class_">UserResponse</span>(<span class="hljs-number">1L</span>, <span class="hljs-string">&quot;a@b.com&quot;</span>, <span class="hljs-string">&quot;Ann&quot;</span>));

        mockMvc.perform(post(<span class="hljs-string">&quot;/api/users&quot;</span>)
                        .contentType(MediaType.APPLICATION_JSON)
                        .content(<span class="hljs-string">&quot;&quot;&quot;
                            {&quot;email&quot;:&quot;a@b.com&quot;,&quot;name&quot;:&quot;Ann&quot;}
                            &quot;&quot;&quot;</span>))
                .andExpect(status().isCreated())
                .andExpect(jsonPath(<span class="hljs-string">&quot;$.email&quot;</span>).value(<span class="hljs-string">&quot;a@b.com&quot;</span>));
    }
}</code></pre>
<p>Security가 켜져 있으면 <code>@WithMockUser</code> 또는 <code>@AutoConfigureMockMvc(addFilters = false)</code>를 명시한다. 필터를 끄면 인가 버그를 놓친다.</p>
<hr>
<h2>4. <code>@DataJpaTest</code>와 Testcontainers</h2>
<p>한 줄 정의: <strong>Testcontainers</strong>는 테스트 동안 Docker로 PostgreSQL 같은 실제 미들웨어를 띄운다. H2는 방언이 달라 운영에서만 깨지는 쿼리가 나온다.</p>
<pre><code class="hljs language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">dependency</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">groupId</span>&gt;</span>org.springframework.boot<span class="hljs-tag">&lt;/<span class="hljs-name">groupId</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">artifactId</span>&gt;</span>spring-boot-testcontainers<span class="hljs-tag">&lt;/<span class="hljs-name">artifactId</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">scope</span>&gt;</span>test<span class="hljs-tag">&lt;/<span class="hljs-name">scope</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">dependency</span>&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">dependency</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">groupId</span>&gt;</span>org.testcontainers<span class="hljs-tag">&lt;/<span class="hljs-name">groupId</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">artifactId</span>&gt;</span>postgresql<span class="hljs-tag">&lt;/<span class="hljs-name">artifactId</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">scope</span>&gt;</span>test<span class="hljs-tag">&lt;/<span class="hljs-name">scope</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">dependency</span>&gt;</span></code></pre>
<pre><code class="hljs language-java"><span class="hljs-meta">@TestConfiguration(proxyBeanMethods = false)</span>
<span class="hljs-keyword">public</span> <span class="hljs-keyword">class</span> <span class="hljs-title class_">TestcontainersConfig</span> {

    <span class="hljs-meta">@Bean</span>
    <span class="hljs-meta">@ServiceConnection</span>
    <span class="hljs-type">PostgreSQLContainer</span>&lt;?&gt; <span class="hljs-title function_">postgres</span><span class="hljs-params">()</span> {
        <span class="hljs-keyword">return</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">PostgreSQLContainer</span>&lt;&gt;(<span class="hljs-string">&quot;postgres:16-alpine&quot;</span>);
    }
}</code></pre>
<p><code>@ServiceConnection</code>(Boot 3.1+)이 datasource URL을 붙인다. <code>@DynamicPropertySource</code>보다 짧다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@DataJpaTest</span>
<span class="hljs-meta">@AutoConfigureTestDatabase(replace = AutoConfigureTestDatabase.Replace.NONE)</span>
<span class="hljs-meta">@Import(TestcontainersConfig.class)</span>
<span class="hljs-keyword">class</span> <span class="hljs-title class_">UserRepositoryTest</span> {

    <span class="hljs-meta">@Autowired</span> UserRepository userRepository;

    <span class="hljs-meta">@Test</span>
    <span class="hljs-type">void</span> <span class="hljs-title function_">findByEmail</span><span class="hljs-params">()</span> {
        userRepository.save(User.create(<span class="hljs-string">&quot;a@b.com&quot;</span>, <span class="hljs-string">&quot;Ann&quot;</span>));
        assertThat(userRepository.findByEmail(<span class="hljs-string">&quot;a@b.com&quot;</span>)).isPresent();
    }
}</code></pre>
<p><code>Replace.ANY</code>(기본)면 H2로 바뀌어 컨테이너를 띄운 의미가 없다.</p>
<hr>
<h2>5. <code>@SpringBootTest</code></h2>
<p>전체 컨텍스트가 필요할 때만 쓴다. HTTP까지 보려면 <code>RANDOM_PORT</code> + <code>TestRestTemplate</code> 또는 MockMvc(<code>@AutoConfigureMockMvc</code>)다. Boot 3.4+에는 <code>RestTestClient</code>도 있다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@SpringBootTest</span>
<span class="hljs-meta">@Import(TestcontainersConfig.class)</span>
<span class="hljs-keyword">class</span> <span class="hljs-title class_">UserServiceIT</span> {

    <span class="hljs-meta">@Autowired</span> UserService userService;

    <span class="hljs-meta">@Test</span>
    <span class="hljs-type">void</span> <span class="hljs-title function_">createAndGet</span><span class="hljs-params">()</span> {
        <span class="hljs-type">UserResponse</span> <span class="hljs-variable">created</span> <span class="hljs-operator">=</span> userService.create(<span class="hljs-keyword">new</span> <span class="hljs-title class_">CreateUserRequest</span>(<span class="hljs-string">&quot;a@b.com&quot;</span>, <span class="hljs-string">&quot;Ann&quot;</span>));
        assertThat(userService.get(created.id()).email()).isEqualTo(<span class="hljs-string">&quot;a@b.com&quot;</span>);
    }
}</code></pre>
<p>Kafka·Redis도 같은 <code>@ServiceConnection</code> 패턴이다.</p>
<hr>
<h2>6. 데이터·시간·외부 의존성</h2>
<p>테스트마다 독립이어야 한다. <code>@Transactional</code> 롤백, 또는 컨테이너 재사용 + 테이블 정리. <code>@Sql</code>은 데이터가 단순할 때만 쓴다.</p>
<pre><code class="hljs language-java"><span class="hljs-keyword">static</span> <span class="hljs-type">User</span> <span class="hljs-title function_">user</span><span class="hljs-params">(String email)</span> {
    <span class="hljs-keyword">return</span> User.create(email, email.split(<span class="hljs-string">&quot;@&quot;</span>)[<span class="hljs-number">0</span>]);
}</code></pre>
<p>AssertJ 체인이 JUnit <code>assertEquals</code>보다 실패 메시지가 읽기 쉽다.</p>
<pre><code class="hljs language-java">assertThat(result)
        .extracting(UserResponse::email, UserResponse::name)
        .containsExactly(<span class="hljs-string">&quot;a@b.com&quot;</span>, <span class="hljs-string">&quot;Ann&quot;</span>);</code></pre>

<h2>7. CI</h2>
<p>러너에 Docker가 있어야 Testcontainers가 돈다. 로컬 재사용은 <code>testcontainers.reuse.enable=true</code>. 실패한 테스트를 재시도로 통과시키지 않는다.</p>
