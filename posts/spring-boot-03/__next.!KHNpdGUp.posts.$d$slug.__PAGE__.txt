<blockquote>
<p>요약: 검증·Problem Details·RestClient로 REST API의 계약과 에러 응답, 외부 호출을 일관되게 만든다.</p>

<h2>1. 컨트롤러는 HTTP 어댑터다</h2>
<p>컨트롤러는 요청을 파싱·검증하고 애플리케이션 서비스를 호출한 뒤, 상태 코드와 본문만 매핑한다. 비즈니스 규칙은 서비스에 둔다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@RestController</span>

<h2>4. Problem Details</h2>
<p>한 줄 정의: <strong>RFC 7807</strong> 형식의 에러 본문이다. <code>type</code>, <code>title</code>, <code>status</code>, <code>detail</code>과 확장 필드로 클라이언트가 분기한다. Boot 3 / Framework 6의 <code>ProblemDetail</code>이 이 계약이다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@RestControllerAdvice</span>
<span class="hljs-keyword">public</span> <span class="hljs-keyword">class</span> <span class="hljs-title class_">GlobalExceptionHandler</span> {

    <span class="hljs-meta">@ExceptionHandler(UserNotFoundException.class)</span>
    <span class="hljs-type">ResponseEntity</span>&lt;ProblemDetail&gt; <span class="hljs-title function_">handleNotFound</span><span class="hljs-params">(UserNotFoundException ex)</span> {
        <span class="hljs-type">ProblemDetail</span> <span class="hljs-variable">problem</span> <span class="hljs-operator">=</span> ProblemDetail.forStatusAndDetail(
                HttpStatus.NOT_FOUND, ex.getMessage());
        problem.setTitle(<span class="hljs-string">&quot;User Not Found&quot;</span>);
        problem.setProperty(<span class="hljs-string">&quot;userId&quot;</span>, ex.getUserId());
        <span class="hljs-keyword">return</span> ResponseEntity.status(HttpStatus.NOT_FOUND).body(problem);
    }

    <span class="hljs-meta">@ExceptionHandler(MethodArgumentNotValidException.class)</span>
    <span class="hljs-type">ResponseEntity</span>&lt;ProblemDetail&gt; <span class="hljs-title function_">handleValidation</span><span class="hljs-params">(MethodArgumentNotValidException ex)</span> {
        <span class="hljs-type">ProblemDetail</span> <span class="hljs-variable">problem</span> <span class="hljs-operator">=</span> ProblemDetail.forStatus(HttpStatus.BAD_REQUEST);
        problem.setTitle(<span class="hljs-string">&quot;Validation Failed&quot;</span>);
        problem.setProperty(<span class="hljs-string">&quot;errors&quot;</span>, ex.getBindingResult().getFieldErrors().stream()
                .map(fe -&gt; Map.of(<span class="hljs-string">&quot;field&quot;</span>, fe.getField(), <span class="hljs-string">&quot;message&quot;</span>, fe.getDefaultMessage()))
                .toList());
        <span class="hljs-keyword">return</span> ResponseEntity.badRequest().body(problem);
    }
}</code></pre>
<pre><code class="hljs language-json"><span class="hljs-punctuation">{</span>
  <span class="hljs-attr">&quot;type&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;about:blank&quot;</span><span class="hljs-punctuation">,</span>

<p>메시지 문자열만 제각각 내려주면 프론트가 필드 단위로 표시하기 어렵다.</p>

<h2>5. 버전·페이지네이션</h2>
<p>중소규모는 URL 버전(<code>/api/v1/users</code>)이 운영하기 쉽다. 필드 추가만 하고, 깨지는 변경은 새 버전으로 둔다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@GetMapping</span>
<span class="hljs-keyword">public</span> <span class="hljs-type">Page</span>&lt;UserResponse&gt; <span class="hljs-title function_">list</span><span class="hljs-params">(Pageable pageable)</span> {
    <span class="hljs-keyword">return</span> userService.list(pageable);
}</code></pre>
<pre><code class="hljs"><span class="hljs-built_in">GET</span> /api/users?<span class="hljs-attribute">page</span>=0&amp;size=20&amp;sort=createdAt,desc</code></pre>
<p>외부 공개 API는 <code>items</code> / <code>page</code> / <code>total</code>처럼 팀 봉투를 따로 정하는 경우가 많다. <code>size</code> 상한을 두지 않으면 한 번에 전체를 끌어가는 요청이 나온다.</p>
<hr>
<h2>6. RestClient</h2>
<p>한 줄 정의: Boot 3.2+의 <strong>동기 HTTP 클라이언트</strong>다. <code>RestTemplate</code>은 유지보수 모드에 가깝고, 리액티브면 <code>WebClient</code>다.</p>
<pre><code class="hljs language-java"><span class="hljs-meta">@Configuration</span>
<span class="hljs-keyword">public</span> <span class="hljs-keyword">class</span> <span class="hljs-title class_">HttpClientConfig</span> {

    <span class="hljs-meta">@Bean</span>
    <span class="hljs-type">RestClient</span> <span class="hljs-title function_">paymentRestClient</span><span class="hljs-params">(RestClient.Builder builder, PaymentProperties props)</span> {
        <span class="hljs-type">JdkClientHttpRequestFactory</span> <span class="hljs-variable">factory</span> <span class="hljs-operator">=</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">JdkClientHttpRequestFactory</span>();
        factory.setReadTimeout(Duration.ofSeconds(<span class="hljs-number">3</span>));
        <span class="hljs-keyword">return</span> builder
                .baseUrl(props.baseUrl())
                .defaultHeader(HttpHeaders.CONTENT_TYPE, MediaType.APPLICATION_JSON_VALUE)
                .requestFactory(factory)
                .build();
    }
}</code></pre>
<pre><code class="hljs language-java"><span class="hljs-keyword">public</span> <span class="hljs-type">PaymentResponse</span> <span class="hljs-title function_">charge</span><span class="hljs-params">(ChargeRequest request)</span> {
    <span class="hljs-keyword">return</span> paymentRestClient.post()
            .uri(<span class="hljs-string">&quot;/charges&quot;</span>)
            .body(request)
            .retrieve()
            .onStatus(HttpStatusCode::is4xxClientError, (req, res) -&gt; {
                <span class="hljs-keyword">throw</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">PaymentRejectedException</span>(<span class="hljs-string">&quot;payment rejected&quot;</span>);
            })
            .body(PaymentResponse.class);
}</code></pre>
<p>타임아웃 없는 클라이언트는 스레드와 커넥션을 붙잡는다. 재시도는 멱등한 호출에만 붙인다.</p>

<h2>7. JSON·OpenAPI</h2>
<pre><code class="hljs language-yaml"><span class="hljs-attr">spring:</span>
  <span class="hljs-attr">jackson:</span>
    <span class="hljs-attr">default-property-inclusion:</span> <span class="hljs-string">non_null</span>
    <span class="hljs-attr">serialization:</span>
      <span class="hljs-attr">write-dates-as-timestamps:</span> <span class="hljs-literal">false</span>
    <span class="hljs-attr">time-zone:</span> <span class="hljs-string">Asia/Seoul</span></code></pre>
<p>날짜는 ISO-8601 (<code>OffsetDateTime</code>)을 쓴다. 문서화는 <code>springdoc-openapi-starter-webmvc-ui</code>로 <code>/swagger-ui.html</code>, <code>/v3/api-docs</code>를 연다. 운영에서는 인증 뒤에 두거나 끈다.</p>
<p>비밀번호·토큰은 응답 DTO에 넣지 않는다. 생성·결제 API는 Idempotency-Key를 검토한다.</p>
