3:T2b2c,<h1>Row·Column·제약으로 레이아웃 잡기</h1>
<blockquote>
<p>요약: 레이아웃은 위젯 이름이 아니라 부모가 내려 준 제약 상자에서 결정된다.</p>
</blockquote>
<hr>
<h2>1. 왜 / 언제</h2>
<p>노란-검은 줄이 보이면 위젯을 더 감싸기 전에 멈춘다. 그 줄은 overflow다. 원인은 거의 항상 <strong>제약을 무시한 자식</strong>이다.</p>
<p>웹의 흐름 레이아웃과 다르다. Flutter는 “부모가 허용한 상자 안에서 자식이 크기를 고른다”. <code>Row</code>에 긴 텍스트를 그냥 넣으면 상자가 터진다. <code>Column</code> 안에 <code>ListView</code>를 무방비로 넣으면 높이가 무한대가 된다.</p>
<p>레이아웃을 고칠 때는 위젯 이름보다 <strong>누가 얼마의 폭·높이를 허용했는가</strong>를 본다.</p>
<hr>
<h2>2. 핵심</h2>
<p>제약은 부모가 자식에게 내리는 규칙이다. 최소 너비, 최대 너비, 최소 높이, 최대 높이다.</p>
<p>레이아웃은 세 단계로 끝난다.</p>
<ol>
<li>부모가 자식에게 제약을 내려 준다.</li>
<li>자식은 그 범위 안에서 자기 크기를 고른다.</li>
<li>부모는 그 크기를 보고 자식의 위치를 정한다.</li>
</ol>
<p>자식이 최대보다 크게 그려지려 하면 overflow다. 반대로 부모가 무한 제약을 주는데 자식이 “가능한 한 크게”를 원하면 예외가 난다. <code>ListView</code>가 대표적이다. 스크롤 뷰는 부모가 유한한 높이를 줘야 한다.</p>
<table>
<thead>
<tr>
<th>위젯</th>
<th>주축</th>
<th>역할</th>
</tr>
</thead>
<tbody><tr>
<td><code>Column</code></td>
<td>세로</td>
<td>위→아래 나열</td>
</tr>
<tr>
<td><code>Row</code></td>
<td>가로</td>
<td>왼쪽→오른쪽 나열</td>
</tr>
<tr>
<td><code>Stack</code></td>
<td>겹침</td>
<td>좌표로 포개기</td>
</tr>
<tr>
<td><code>Wrap</code></td>
<td>줄바꿈</td>
<td>주축이 부족하면 다음 줄</td>
</tr>
<tr>
<td><code>Expanded</code></td>
<td>Flex 남은 공간</td>
<td><code>Row</code>/<code>Column</code> 자식만</td>
</tr>
</tbody></table>
<p><code>Row</code>의 주축은 가로다. 자식들의 고유 너비 합이 부모 최대 너비를 넘으면 overflow다. 남는 공간을 나눠 가질 자식에게 <code>Expanded</code> 또는 <code>Flexible</code>을 준다.</p>
<p><code>Padding</code>은 안쪽 여백이다. <code>SafeArea</code>는 노치·시스템 바를 피한다. 간격은 <code>SizedBox</code>로 명시한다. 임의 margin을 여러 겹 쌓지 않는다.</p>
<hr>
<h2>3. 예제</h2>

  <span class="hljs-keyword">final</span> <span class="hljs-title class_">String</span> title;

  <span class="hljs-meta">@override</span>

    <span class="hljs-keyword">return</span> <span class="hljs-title class_">Row</span>(
      children: [
        <span class="hljs-keyword">const</span> <span class="hljs-title class_">Icon</span>(<span class="hljs-title class_">Icons</span>.star),

<p>아이콘은 고유 너비를 갖는다. <code>Expanded</code>가 남은 가로를 텍스트에 준다. 텍스트는 그 안에서 줄임표를 쓴다. <code>Expanded</code> 없이 <code>Text</code>만 두면 긴 제목이 overflow를 만든다.</p>
<h3>Column + 스크롤 목록</h3>
<p>무한 높이(<code>Column</code>이 스크롤 없이 자식 고유 높이를 잴 때) 안에 <code>ListView</code>를 두면 실패한다. 목록은 유한한 높이를 받아야 한다.</p>
<pre><code class="hljs language-dart"><span class="hljs-class"><span class="hljs-keyword">class</span> <span class="hljs-title">FeedBody</span> <span class="hljs-keyword">extends</span> <span class="hljs-title">StatelessWidget</span> </span>{
  <span class="hljs-keyword">const</span> <span class="hljs-title class_">FeedBody</span>({<span class="hljs-keyword">super</span>.key, <span class="hljs-keyword">required</span> <span class="hljs-keyword">this</span>.children});

  <span class="hljs-keyword">final</span> <span class="hljs-title class_">List</span>&lt;<span class="hljs-title class_">Widget</span>&gt; children;

  <span class="hljs-meta">@override</span>
  <span class="hljs-title class_">Widget</span> <span class="hljs-title function_">build</span>(<span class="hljs-title class_">BuildContext</span> context) {
    <span class="hljs-keyword">return</span> <span class="hljs-title class_">Column</span>(
      children: [
        <span class="hljs-keyword">const</span> <span class="hljs-title class_">Padding</span>(
          padding: <span class="hljs-title class_">EdgeInsets</span>.<span class="hljs-title function_">all</span>(<span class="hljs-number">16</span>),
          child: <span class="hljs-title class_">Text</span>(<span class="hljs-string">&#x27;피드&#x27;</span>),
        ),
        <span class="hljs-title class_">Expanded</span>(
          child: <span class="hljs-title class_">ListView</span>(
            children: children,
          ),
        ),
      ],
    );
  }
}</code></pre>
<p>바깥이 <code>Scaffold</code>의 <code>body</code>면 높이가 유한하다. <code>Expanded</code>가 그 남은 높이를 <code>ListView</code>에 넘긴다.</p>
<p><code>shrinkWrap: true</code>는 목록이 자식 높이만큼만 차지하게 한다. 긴 목록에서 가상화를 포기하므로 기본값으로 쓰지 않는다.</p>

<p>테두리와 여백이 보인다. overflow 줄이 보이면 위젯을 더 넣기 전에 제약부터 고친다.</p>
<hr>
<h2>4. 흔한 실수</h2>
<table>
<thead>
<tr>
<th>실수</th>
<th>일어나는 일</th>
<th>대안</th>
</tr>
</thead>
<tbody><tr>
<td><code>Row</code>에 긴 <code>Text</code>만 넣는다</td>
<td>가로 overflow</td>
<td><code>Expanded</code> / <code>Flexible</code></td>
</tr>
<tr>
<td><code>Column</code> 안에 <code>ListView</code></td>
<td>세로 무한 제약 예외</td>
<td><code>Expanded</code> 또는 바깥을 스크롤</td>
</tr>
<tr>
<td><code>width: double.infinity</code> 남발</td>
<td>부모가 무한이면 깨진다</td>
<td>제약에 맞게 <code>Expanded</code></td>
</tr>
<tr>
<td>모든 간격을 <code>margin</code></td>
<td>누가 공간을 쓰는지 안 보인다</td>
<td><code>Padding</code> + <code>SizedBox</code></td>
</tr>
<tr>
<td><code>Stack</code> 자식을 제약 없이 둔다</td>
<td>크기 0 또는 화면 전체</td>
<td><code>Positioned</code> + 명시 크기</td>
</tr>
</tbody></table>
<p><code>Flexible</code>은 자식이 작으면 작아도 된다. <code>Expanded</code>는 <code>flex</code> 비율로 남은 공간을 채운다. 텍스트 한 줄은 보통 <code>Expanded</code>다.</p>
<p><code>Wrap</code>은 칩·태그처럼 줄바꿈이 자연스러울 때 쓴다. <code>Row</code> overflow의 만능 대체는 아니다. 한 줄 제목은 <code>Expanded</code>가 맞다.</p>
<hr>
<h2>정리</h2>
<p>레이아웃 버그는 위젯 이름에서 시작하지 않는다. <strong>누가 얼마의 폭·높이를 허용했는가</strong>에서 시작한다. 부모는 제약을 주고, 자식은 그 안에서 크기를 고른다.</p>
<hr>
<h2>연습</h2>
<ol>
<li>아이콘 + 긴 제목 <code>Row</code>를 만들고, <code>Expanded</code> 전후에 overflow를 비교한다.</li>
<li><code>Column</code> 헤더 아래 <code>ListView</code>를 <code>Expanded</code>로 넣어 스크롤되게 한다.</li>
<li><code>debugPaintSizeEnabled</code>로 여백과 제약 상자를 확인한다.</li>
<li><code>shrinkWrap: true</code> 목록을 긴 데이터로 바꿔 보고, 왜 빌더 리스트로 바꿔야 하는지 적는다.</li>
</ol>
