3:T2753,<h1>WPF와 XAML·MVVM 시작하기</h1>
<blockquote>
<p>요약: XAML로 화면을 그리고, DataContext로 ViewModel을 붙여 화면과 로직을 나눈다.</p>
</blockquote>
<hr>
<h2>1. 언제 WPF인가</h2>
<p>WPF(Windows Presentation Foundation)는 .NET으로 Windows 데스크톱 UI를 만드는 프레임워크다. 화면은 XAML(마크업)로 선언하고, 동작은 C#으로 둔다.</p>
<p>WinForms는 코드에서 컨트롤을 직접 만지는 비중이 크다. WPF는 <strong>데이터 바인딩</strong>이 기본이라, 화면과 상태를 분리하기 쉽다. 대상이 Windows이고 .NET을 쓰는 내부 도구·클라이언트라면 WPF가 맞다. 웹·크로스플랫폼은 다른 스택을 고른다.</p>
<table>
<thead>
<tr>
<th>항목</th>
<th>역할</th>
</tr>
</thead>
<tbody><tr>
<td>XAML</td>
<td>컨트롤 트리와 바인딩을 선언한다</td>
</tr>
<tr>
<td>C#</td>
<td>계산·명령·서비스 호출</td>
</tr>
<tr>
<td>MVVM</td>
<td>View / ViewModel / Model 세 층</td>
</tr>
<tr>
<td>DataContext</td>
<td>이 화면이 바라보는 데이터 소스</td>
</tr>
</tbody></table>
<p>실무 기본선: <strong>.NET 8/9 + WPF + MVVM + CommunityToolkit.Mvvm</strong>.</p>
<hr>
<h2>2. 핵심 개념</h2>
<p>MVVM(Model-View-ViewModel)은 화면 코드와 비즈니스 상태를 나누는 패턴이다.</p>
<table>
<thead>
<tr>
<th>층</th>
<th>한 줄</th>
</tr>
</thead>
<tbody><tr>
<td>View</td>
<td><code>.xaml</code>. 컨트롤과 <code>{Binding}</code>. 가능하면 코드비하인드에 로직을 두지 않는다</td>
</tr>
<tr>
<td>ViewModel</td>
<td>화면이 보여줄 값과 명령. UI 타입(<code>Button</code>, <code>Window</code>)을 참조하지 않는다</td>
</tr>
<tr>
<td>Model</td>
<td>엔티티·DTO. UI를 모른다</td>
</tr>
<tr>
<td>DataContext</td>
<td>View가 바인딩할 객체. 보통 ViewModel 인스턴스</td>
</tr>
</tbody></table>
<p>코드비하인드(<code>MainWindow.xaml.cs</code>)의 <code>Click</code> 핸들러에 저장 로직을 넣으면 테스트가 창을 띄워야 한다. 명령은 ViewModel의 <code>ICommand</code>로 올린다. 3편에서 다룬다.</p>
<hr>
<h2>3. 생성</h2>
<pre><code class="hljs language-bash">dotnet new wpf -n MyApp -f net9.0
<span class="hljs-built_in">cd</span> MyApp
dotnet add package CommunityToolkit.Mvvm
dotnet run</code></pre>
<p>폴더 감각:</p>
<pre><code class="hljs"><span class="hljs-title class_">App</span>.xaml
<span class="hljs-title class_">App</span>.xaml.cs
<span class="hljs-title class_">Views</span>/<span class="hljs-title class_">MainWindow</span>.xaml
<span class="hljs-title class_">Views</span>/<span class="hljs-title class_">MainWindow</span>.xaml.cs
<span class="hljs-title class_">ViewModels</span>/<span class="hljs-title class_">MainViewModel</span>.cs
<span class="hljs-title class_">Models</span>/
<span class="hljs-title class_">Services</span>/</code></pre>
<p>템플릿 기본은 <code>MainWindow</code>가 프로젝트 루트에 있다. 규모가 생기면 <code>Views/</code>로 옮기고 <code>App.xaml</code>의 <code>StartupUri</code>를 맞춘다.</p>
<hr>
<h2>4. 동작하는 예: 제목 바인딩</h2>
<p><code>ViewModels/MainViewModel.cs</code>:</p>
<pre><code class="hljs language-csharp"><span class="hljs-keyword">using</span> CommunityToolkit.Mvvm.ComponentModel;

<span class="hljs-keyword">namespace</span> <span class="hljs-title">MyApp.ViewModels</span>;

<span class="hljs-keyword">public</span> <span class="hljs-keyword">partial</span> <span class="hljs-keyword">class</span> <span class="hljs-title">MainViewModel</span> : <span class="hljs-title">ObservableObject</span>
{
    [<span class="hljs-meta">ObservableProperty</span>]
    <span class="hljs-keyword">private</span> <span class="hljs-built_in">string</span> title = <span class="hljs-string">&quot;Hello WPF&quot;</span>;
}</code></pre>
<p><code>ObservableObject</code> + <code>[ObservableProperty]</code>는 속성 변경 시 UI에 “이 값이 바뀌었다”고 알리는 코드를 생성한다. 직접 <code>INotifyPropertyChanged</code>(속성 변경 알림)를 적어도 된다. 툴킷이 반복을 줄인다.</p>
<p><code>Views/MainWindow.xaml</code>:</p>
<pre><code class="hljs language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">Window</span> <span class="hljs-attr">x:Class</span>=<span class="hljs-string">&quot;MyApp.Views.MainWindow&quot;</span>
        <span class="hljs-attr">xmlns</span>=<span class="hljs-string">&quot;http://schemas.microsoft.com/winfx/2006/xaml/presentation&quot;</span>
        <span class="hljs-attr">xmlns:x</span>=<span class="hljs-string">&quot;http://schemas.microsoft.com/winfx/2006/xaml&quot;</span>
        <span class="hljs-attr">xmlns:vm</span>=<span class="hljs-string">&quot;clr-namespace:MyApp.ViewModels&quot;</span>
        <span class="hljs-attr">Title</span>=<span class="hljs-string">&quot;MyApp&quot;</span> <span class="hljs-attr">Height</span>=<span class="hljs-string">&quot;240&quot;</span> <span class="hljs-attr">Width</span>=<span class="hljs-string">&quot;400&quot;</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">Window.DataContext</span>&gt;</span>
    <span class="hljs-tag">&lt;<span class="hljs-name">vm:MainViewModel</span> /&gt;</span>
  <span class="hljs-tag">&lt;/<span class="hljs-name">Window.DataContext</span>&gt;</span>
  <span class="hljs-tag">&lt;<span class="hljs-name">StackPanel</span> <span class="hljs-attr">Margin</span>=<span class="hljs-string">&quot;16&quot;</span>&gt;</span>
    <span class="hljs-tag">&lt;<span class="hljs-name">TextBlock</span> <span class="hljs-attr">Text</span>=<span class="hljs-string">&quot;{Binding Title}&quot;</span> <span class="hljs-attr">FontSize</span>=<span class="hljs-string">&quot;20&quot;</span> /&gt;</span>
    <span class="hljs-tag">&lt;<span class="hljs-name">TextBox</span> <span class="hljs-attr">Text</span>=<span class="hljs-string">&quot;{Binding Title, UpdateSourceTrigger=PropertyChanged}&quot;</span> <span class="hljs-attr">Margin</span>=<span class="hljs-string">&quot;0,8,0,0&quot;</span> /&gt;</span>
  <span class="hljs-tag">&lt;/<span class="hljs-name">StackPanel</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">Window</span>&gt;</span></code></pre>
<p><code>TextBox</code>를 바꾸면 <code>Title</code>이 바뀌고 <code>TextBlock</code>이 따라간다. DataContext가 ViewModel이므로 <code>{Binding Title}</code>은 <code>MainViewModel.Title</code>이다.</p>
<p><code>Views/MainWindow.xaml.cs</code>는 생성자 <code>InitializeComponent()</code>만 둔다.</p>
<pre><code class="hljs language-csharp"><span class="hljs-keyword">using</span> System.Windows;

<span class="hljs-keyword">namespace</span> <span class="hljs-title">MyApp.Views</span>;

<span class="hljs-keyword">public</span> <span class="hljs-keyword">partial</span> <span class="hljs-keyword">class</span> <span class="hljs-title">MainWindow</span> : <span class="hljs-title">Window</span>
{
    <span class="hljs-function"><span class="hljs-keyword">public</span> <span class="hljs-title">MainWindow</span>()</span>
    {
        InitializeComponent();
    }
}</code></pre>
<p><code>App.xaml</code>:</p>
<pre><code class="hljs language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">Application</span> <span class="hljs-attr">x:Class</span>=<span class="hljs-string">&quot;MyApp.App&quot;</span>
             <span class="hljs-attr">xmlns</span>=<span class="hljs-string">&quot;http://schemas.microsoft.com/winfx/2006/xaml/presentation&quot;</span>
             <span class="hljs-attr">xmlns:x</span>=<span class="hljs-string">&quot;http://schemas.microsoft.com/winfx/2006/xaml&quot;</span>
             <span class="hljs-attr">StartupUri</span>=<span class="hljs-string">&quot;Views/MainWindow.xaml&quot;</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">Application</span>&gt;</span></code></pre>
<p>XAML에서 ViewModel을 <code>new</code>하는 방식은 작은 앱에 충분하다. DI 컨테이너로 주입하는 방식은 서비스가 늘 때 검토한다.</p>
<hr>
<h2>5. 코드비하인드와 경계</h2>
<p>허용에 가까운 것: 포커스 이동, 패스워드 박스처럼 바인딩이 약한 컨트롤 접착.</p>
<p>피한다: 파일 저장, 메시지 박스 직접 호출, HTTP. 저장은 ViewModel 명령, 대화상자는 서비스(5편).</p>
<p>리소스·스타일은 창마다 복사하지 않고 <code>App.xaml</code> 또는 ResourceDictionary로 뺀다. 4편.</p>
<hr>
<h2>6. 주의 / 흔한 실수</h2>
<ul>
<li><strong>DataContext를 안 넣고 <code>{Binding Title}</code>.</strong> 출력은 비고, 출력창에 바인딩 오류가 난다. Visual Studio 출력 창을 본다.</li>
<li><strong>ViewModel에서 <code>MessageBox.Show</code>.</strong> View가 테스트에 딸려 온다. 인터페이스로 감싼다.</li>
<li><strong>코드비하인드에서 컨트롤 이름으로 값을 읽기.</strong> <code>txtName.Text</code>는 MVVM이 아니다. 바인딩한다.</li>
<li><strong><code>partial class</code> 이름·네임스페이스가 XAML <code>x:Class</code>와 다름.</strong> 빌드가 실패한다.</li>
<li><strong>.NET Framework 전용 WPF 템플릿으로 신규 시작.</strong> 신규는 SDK 스타일 + <code>net8.0-windows</code> / <code>net9.0-windows</code>다.</li>
</ul>
<hr>
<h2>정리</h2>
<p>WPF 시작은 컨트롤 암기가 아니다. <strong>XAML + DataContext + ViewModel</strong> 경계를 먼저 고정한다.</p>
<ul>
<li>화면 → XAML</li>
<li>이 화면의 데이터 소스 → DataContext = ViewModel</li>
<li>로직 → ViewModel (창 타입 없이)</li>
</ul>
<hr>
<h2>연습</h2>
<ol>
<li><code>dotnet new wpf</code> 후 위 ViewModel을 붙여 TextBox와 TextBlock이 같은 <code>Title</code>을 쓰는지 확인한다.</li>
<li><code>Subtitle</code> 속성을 추가하고 두 번째 <code>TextBlock</code>에 바인딩한다.</li>
<li><code>StartupUri</code>를 <code>Views/MainWindow.xaml</code>로 옮긴 뒤 앱이 켜지는지 확인한다.</li>
</ol>
