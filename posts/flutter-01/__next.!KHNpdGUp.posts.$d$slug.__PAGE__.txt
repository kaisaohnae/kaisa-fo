3:T1eb1,<h1>Flutter SDK와 프로젝트 시작하기</h1>
<blockquote>
<p>요약: Flutter SDK를 설치하고 프로젝트 구조를 이해한 뒤, 실제 기기에서 첫 앱을 실행한다.</p>
</blockquote>
<hr>
<h2>1. 왜 / 언제</h2>
<p>한 코드베이스로 iOS·Android·웹·데스크톱 UI를 만든다. 언어는 Dart다. 화면은 위젯을 겹겹이 조합한 <strong>위젯 트리</strong>다.</p>
<p>위젯은 “이렇게 그려라”는 설명이다. 버튼, 여백, 앱 전체까지 모두 위젯이다. 트리는 루트에서 잎으로 내려가며 그려진다.</p>
<p>실무 기본 조합은 <strong>안정 채널 SDK + VS Code 또는 Android Studio + 실제 기기 한 대</strong>다. 에뮬레이터만 쓰면 터치·성능 감각이 어긋난다.</p>
<p>이 글은 위젯 API를 외우기 전에, <strong>doctor가 통과하는 환경</strong>과 <strong>재현 가능한 <code>flutter create</code></strong> 를 고정한다.</p>
<hr>
<h2>2. 핵심</h2>
<p>설치가 끝났는지는 IDE가 아니라 <code>flutter doctor</code>가 판단한다. 빨간 항목은 배포 전에 없앤다.</p>
<table>
<thead>
<tr>
<th>대상</th>
<th>필요한 것</th>
</tr>
</thead>
<tbody><tr>
<td>Android</td>
<td>cmdline-tools, 라이선스, 에뮬레이터 또는 USB 디버깅</td>
</tr>
<tr>
<td>iOS</td>
<td>macOS + Xcode + CocoaPods</td>
</tr>
<tr>
<td>웹</td>
<td>Chrome (선택)</td>
</tr>
</tbody></table>
<p>프로젝트 루트의 <code>pubspec.yaml</code>이 의존성·에셋·버전 계약이다. <code>lib/main.dart</code>가 진입점이다. <code>main()</code>에서 <code>runApp</code>으로 루트 위젯을 올린다.</p>
<p>기능 단위 폴더를 일찍 나눈다. 화면·도메인·데이터가 한 파일에 쌓이면 위젯 트리를 읽기 어려워진다.</p>
<hr>
<h2>3. 예제</h2>
<h3>설치 확인</h3>
<pre><code class="hljs language-bash">flutter doctor
flutter devices</code></pre>
<p><code>doctor</code>는 체크리스트다. 라이선스 미동의, cmdline-tools 누락, 연결된 기기 없음이 흔하다.</p>
<pre><code class="hljs language-bash">flutter doctor --android-licenses</code></pre>
<h3>생성·실행</h3>
<pre><code class="hljs language-bash">flutter create my_app
<span class="hljs-built_in">cd</span> my_app
flutter pub get
flutter run</code></pre>
<p>기기가 여러 대면 <code>-d</code>로 고른다.</p>
<pre><code class="hljs language-bash">flutter devices
flutter run -d chrome
flutter run -d windows</code></pre>
<h3>진입점</h3>
<pre><code class="hljs language-dart"><span class="hljs-keyword">import</span> <span class="hljs-string">&#x27;package:flutter/material.dart&#x27;</span>;

<span class="hljs-keyword">void</span> <span class="hljs-title function_">main</span>() {
  <span class="hljs-title function_">runApp</span>(<span class="hljs-keyword">const</span> <span class="hljs-title class_">MyApp</span>());
}

<span class="hljs-class"><span class="hljs-keyword">class</span> <span class="hljs-title">MyApp</span> <span class="hljs-keyword">extends</span> <span class="hljs-title">StatelessWidget</span> </span>{
  <span class="hljs-keyword">const</span> <span class="hljs-title class_">MyApp</span>({<span class="hljs-keyword">super</span>.key});

  <span class="hljs-meta">@override</span>
  <span class="hljs-title class_">Widget</span> <span class="hljs-title function_">build</span>(<span class="hljs-title class_">BuildContext</span> context) {
    <span class="hljs-keyword">return</span> <span class="hljs-keyword">const</span> <span class="hljs-title class_">MaterialApp</span>(
      home: <span class="hljs-title class_">Scaffold</span>(
        body: <span class="hljs-title class_">Center</span>(
          child: <span class="hljs-title class_">Text</span>(<span class="hljs-string">&#x27;Hello, Flutter&#x27;</span>),
        ),
      ),
    );
  }
}</code></pre>
<p><code>runApp</code>이 루트 위젯을 붙인다. 그 아래 <code>MaterialApp</code> → <code>Scaffold</code> → <code>Center</code> → <code>Text</code>가 위젯 트리다. <code>const</code> 생성자는 변하지 않는 서브트리를 재사용한다.</p>
<h3>디렉터리</h3>
<pre><code class="hljs">lib<span class="hljs-symbol">/</span>
├── main.dart
├── app.dart
└── features<span class="hljs-symbol">/</span>
    └── home<span class="hljs-symbol">/</span>
android<span class="hljs-symbol">/</span>   ios<span class="hljs-symbol">/</span>   web<span class="hljs-symbol">/</span>
pubspec.yaml
test<span class="hljs-operator">/</span></code></pre>
<p>에셋은 파일만 두면 번들에 안 들어간다. <code>pubspec.yaml</code>에 등록한다.</p>
<pre><code class="hljs language-yaml"><span class="hljs-attr">name:</span> <span class="hljs-string">my_app</span>
<span class="hljs-attr">description:</span> <span class="hljs-string">A</span> <span class="hljs-string">Flutter</span> <span class="hljs-string">starter.</span>
<span class="hljs-attr">publish_to:</span> <span class="hljs-string">&quot;none&quot;</span>
<span class="hljs-attr">version:</span> <span class="hljs-number">1.0</span><span class="hljs-number">.0</span><span class="hljs-string">+1</span>

<span class="hljs-attr">environment:</span>
  <span class="hljs-attr">sdk:</span> <span class="hljs-string">&quot;&gt;=3.5.0 &lt;4.0.0&quot;</span>

<span class="hljs-attr">dependencies:</span>
  <span class="hljs-attr">flutter:</span>
    <span class="hljs-attr">sdk:</span> <span class="hljs-string">flutter</span>

<span class="hljs-attr">flutter:</span>
  <span class="hljs-attr">uses-material-design:</span> <span class="hljs-literal">true</span>
  <span class="hljs-attr">assets:</span>
    <span class="hljs-bullet">-</span> <span class="hljs-string">assets/images/</span></code></pre>
<p>버전 <code>1.0.0+1</code>에서 <code>+1</code>은 빌드 번호다. 스토어 제출 때 올린다.</p>
<hr>
<h2>4. 흔한 실수</h2>
<table>
<thead>
<tr>
<th>실수</th>
<th>결과</th>
<th>대안</th>
</tr>
</thead>
<tbody><tr>
<td><code>doctor</code>를 건너뛴다</td>
<td>기기·라이선스 오류가 첫 <code>run</code>에서 터진다</td>
<td>생성 전에 doctor 통과</td>
</tr>
<tr>
<td>에셋을 yaml에 안 적는다</td>
<td>런타임에 이미지를 못 찾는다</td>
<td><code>flutter:</code> 아래 <code>assets</code> 등록</td>
</tr>
<tr>
<td>모든 UI를 <code>main.dart</code>에 쌓는다</td>
<td>트리를 추적할 수 없다</td>
<td><code>features/</code>로 화면 분리</td>
</tr>
<tr>
<td>베타 채널로 시작한다</td>
<td>플러그인·문서와 어긋난다</td>
<td>안정 채널</td>
</tr>
<tr>
<td>에뮬레이터만 쓴다</td>
<td>제스처·성능이 실제와 다르다</td>
<td>실기기 한 대</td>
</tr>
</tbody></table>
<p>채널 확인:</p>
<pre><code class="hljs language-bash">flutter channel
flutter channel stable
flutter upgrade</code></pre>
<p>Hot reload는 상태 있는 화면을 유지한 채 UI만 고친다. 플러그인·엔트리 변경은 Hot restart 또는 재실행이 필요하다.</p>
<hr>
<h2>정리</h2>
<p>Flutter 시작은 위젯 암기가 아니다. <strong>doctor가 통과하는 환경</strong>과 <strong><code>lib/main.dart</code>에서 시작하는 위젯 트리</strong>를 재현 가능하게 만드는 일이다.</p>
<p>다음 글에서 Stateless와 Stateful의 차이를 같은 트리 관점으로 본다.</p>
<hr>
<h2>연습</h2>
<ol>
<li><code>flutter doctor</code>를 실행하고 빨간 항목을 없앤다.</li>
<li><code>flutter create</code> 후 실기기에서 <code>flutter run</code>으로 Hello 화면을 띄운다.</li>
<li><code>assets/images/</code>를 만들고 <code>pubspec.yaml</code>에 등록한 뒤 이미지를 화면에 넣는다.</li>
<li><code>MyApp</code>을 <code>lib/app.dart</code>로 옮기고 <code>main.dart</code>는 <code>runApp</code>만 남긴다.</li>
</ol>
