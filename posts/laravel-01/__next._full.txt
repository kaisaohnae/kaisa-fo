24:T2f2b,<h1>Laravel 11+와 PHP 시작하기</h1>
<blockquote>
<p>요약: Laravel 11부터는 Kernel 대신 bootstrap/app.php가 앱의 중심이고, PHP 8.2 이상으로 프로젝트를 세팅한다.</p>
</blockquote>
<hr>
<h2>1. Laravel이란, 왜 11+인가</h2>
<p><strong>Laravel</strong>은 PHP로 웹 앱과 API를 만드는 프레임워크다. 라우팅·DB·인증·큐처럼 반복되는 뼈대를 대신 제공해서, 도메인 코드에 시간을 쓰게 한다.</p>
<p>11부터는 <strong>골격은 얇게, 기능은 필요할 때 패키지로</strong> 가는 방향이다. 예전처럼 Kernel과 설정 파일이 잔뜩 깔려 있지 않다.</p>
<table>
<thead>
<tr>
<th>항목</th>
<th>Laravel 8~10</th>
<th>Laravel 11+</th>
</tr>
</thead>
<tbody><tr>
<td>앱 구성</td>
<td><code>Http/Kernel</code>, <code>RouteServiceProvider</code></td>
<td><strong><code>bootstrap/app.php</code></strong></td>
</tr>
<tr>
<td>PHP</td>
<td>8.0~8.1도 가능</td>
<td><strong>8.2+</strong> (8.3 권장)</td>
</tr>
<tr>
<td>미들웨어</td>
<td>Kernel에 배열 등록</td>
<td><code>withMiddleware</code> / 별칭</td>
</tr>
<tr>
<td>테스트</td>
<td>PHPUnit 기본</td>
<td><strong>Pest</strong>를 쓰는 팀이 많음</td>
</tr>
</tbody></table>
<p>실무 기본선은 <strong>PHP 8.3 + Laravel 11/12 + Composer 2</strong>다.</p>
<hr>
<h2>2. 설치</h2>
<pre><code class="hljs language-bash">composer create-project laravel/laravel demo
<span class="hljs-comment"># 또는</span>
laravel new demo

<span class="hljs-built_in">cd</span> demo
<span class="hljs-built_in">cp</span> .env.example .<span class="hljs-built_in">env</span>
php artisan key:generate
php artisan serve</code></pre>
<p>필요한 것: PHP 8.2+, Composer, DB(SQLite/MySQL/PostgreSQL). 프론트를 빌드하면 Node도 필요하다.</p>
<p>로컬을 Docker로 맞출 때는 <strong>Sail</strong>(공식 Docker 구성)을 쓴다. 운영 이미지로 그대로 쓰지 않는 편이 안전하다.</p>
<pre><code class="hljs language-bash">php artisan sail:install
./vendor/bin/sail up -d</code></pre>

<h2>4. <code>.env</code>와 설정</h2>
<pre><code class="hljs language-env"><span class="hljs-attr">APP_NAME</span><span class="hljs-operator">=</span>Demo
<span class="hljs-attr">APP_ENV</span><span class="hljs-operator">=</span>local
<span class="hljs-attr">APP_DEBUG</span><span class="hljs-operator">=</span><span class="hljs-literal">true</span>
<span class="hljs-attr">APP_URL</span><span class="hljs-operator">=</span>http://localhost

<span class="hljs-attr">DB_CONNECTION</span><span class="hljs-operator">=</span>sqlite

<span class="hljs-attr">CACHE_STORE</span><span class="hljs-operator">=</span>database
<span class="hljs-attr">QUEUE_CONNECTION</span><span class="hljs-operator">=</span>database
<span class="hljs-attr">SESSION_DRIVER</span><span class="hljs-operator">=</span>database</code></pre>
<p>규칙이 세 가지다.</p>
<ul>
<li>비밀번호·키는 <code>.env</code>에만 두고 <strong>커밋하지 않는다</strong>.</li>
<li>앱 코드에서는 <code>config(&#39;app.name&#39;)</code>을 쓴다. <code>env()</code>는 <strong>config 파일 안에서만</strong>.</li>
<li>운영은 <code>APP_ENV=production</code>이면 <code>APP_DEBUG=false</code>가 필수다. 디버그가 켜지면 스택과 환경 값이 그대로 보인다.</li>
</ul>
<p><code>config:cache</code>를 켠 뒤에는 <code>env()</code>가 코드에서 빈 값을 돌려주는 경우가 많다. 그래서 코드에 <code>env()</code>를 두면 운영에서만 깨진다.</p>
<pre><code class="hljs language-bash">php artisan config:cache   <span class="hljs-comment"># 운영 배포</span>
php artisan config:clear   <span class="hljs-comment"># 로컬에서 .env를 바꾼 뒤</span></code></pre>

    <span class="hljs-title class_">OrderStatus</span>::<span class="hljs-variable constant_">Pending</span> =&gt; <span class="hljs-string">&#x27;대기&#x27;</span>,
    <span class="hljs-title class_">OrderStatus</span>::<span class="hljs-variable constant_">Paid</span> =&gt; <span class="hljs-string">&#x27;결제완료&#x27;</span>,
    <span class="hljs-title class_">OrderStatus</span>::<span class="hljs-variable constant_">Cancelled</span> =&gt; <span class="hljs-string">&#x27;취소&#x27;</span>,
};</code></pre>
<p>상태 값을 문자열 <code>&#39;paid&#39;</code>로 흩뿌리면 오타가 컴파일에 안 잡힌다. Enum이면 잘못된 값이 타입에서 걸린다.</p>
<hr>
<h2>6. Artisan</h2>
<p><strong>Artisan</strong>은 Laravel 명령줄 도구다. 모델·마이그레이션·컨트롤러를 손으로 복사하지 않는다.</p>
<pre><code class="hljs language-bash">php artisan list
php artisan make:model Post -mfs   <span class="hljs-comment"># model + migration + factory + seeder</span>
php artisan make:controller PostController --resource
php artisan migrate
php artisan route:list
php artisan tinker</code></pre>
<p><code>tinker</code>는 컨테이너와 Eloquent(DB를 객체로 다루는 계층, 3편)를 REPL에서 만져 보는 도구다. 쿼리를 추측하기 전에 한 번 실행해 보면 학습이 빨라진다.</p>
<hr>
<h2>7. 첫 라우트</h2>
<pre><code class="hljs language-php"><span class="hljs-comment">// routes/web.php</span>
<span class="hljs-keyword">use</span> <span class="hljs-title">Illuminate</span>\<span class="hljs-title">Support</span>\<span class="hljs-title">Facades</span>\<span class="hljs-title">Route</span>;

<span class="hljs-title class_">Route</span>::<span class="hljs-title function_ invoke__">get</span>(<span class="hljs-string">&#x27;/api/hello&#x27;</span>, function () {
    <span class="hljs-keyword">return</span> <span class="hljs-title function_ invoke__">response</span>()-&gt;<span class="hljs-title function_ invoke__">json</span>([<span class="hljs-string">&#x27;message&#x27;</span> =&gt; <span class="hljs-string">&#x27;Hello, Laravel&#x27;</span>]);
});</code></pre>
<pre><code class="hljs language-bash">curl http://127.0.0.1:8000/api/hello
php artisan route:list</code></pre>
<p>웹 세션이 필요 없는 JSON API만 만들면 <code>php artisan install:api</code>로 <code>routes/api.php</code>를 추가한다.</p>

<h2>9. 흔한 실수</h2>
<ul>
<li>Laravel 10 문서만 보고 <code>Http/Kernel.php</code>를 찾는다. 11+는 <code>bootstrap/app.php</code>다.</li>
<li>컨트롤러에서 <code>env(&#39;APP_URL&#39;)</code>을 직접 읽는다. 설정 캐시 후 빈 값이 된다.</li>
<li><code>.env</code>를 깃에 올린다. <code>APP_KEY</code>가 새면 세션·암호화 데이터가 위험해진다.</li>
<li><code>APP_DEBUG=true</code>인 채 배포한다.</li>
<li>PHP 8.1로 11을 설치하려고 한다. 최소 8.2다.</li>
</ul>

<ol>
<li>프로젝트를 만들고 <code>/up</code>과 JSON 라우트가 응답하는지 확인한다.</li>
<li><code>.env</code>에서 SQLite 또는 MySQL/Postgres 중 하나로 DB를 연결한다.</li>
<li><code>OrderStatus</code> Enum을 만들어 <code>tinker</code>에서 출력한다.</li>
<li><code>php artisan route:list</code>로 등록된 경로를 확인한다.</li>
