URL

URL 또는 쿼리 값을 퍼센트 인코딩/디코딩합니다. (encodeURIComponent / encodeURI)

사용 안내사용 방법 · 실무 팁 · 자주 묻는 질문

URL에 들어갈 수 없는 한글·공백·특수문자를 퍼센트 인코딩(%EC%95%88…)하거나 반대로 디코딩합니다. 쿼리 값만 바꾸는 방식과 전체 URL 방식 중 고를 수 있습니다.

사용 방법

  1. 변환할 검색어·경로·URL을 입력합니다.
  2. 모드를 고릅니다: 값 하나(encodeURIComponent) 또는 전체 URL(encodeURI).
  3. 인코딩 또는 디코딩을 누르고 결과를 복사합니다.

실무에서 알아 두면 좋은 점

  • 쿼리스트링의 값 하나를 넣을 때는 값 모드를 써야 &, =, / 까지 안전하게 바뀝니다.
  • 전체 URL 모드는 주소 구조(:, /, ?, &)를 그대로 둡니다.
  • 로그에 찍힌 인코딩된 주소를 디코딩하면 어떤 검색어였는지 바로 읽을 수 있습니다.

자주 묻는 질문

입력한 내용이 저장되나요?
아니요. 입력한 텍스트는 브라우저 안에서만 처리되며 서버로 전송되지 않습니다. 페이지를 닫으면 사라지니 결과는 복사해 두세요.
두 모드는 무엇이 다른가요?
값 모드는 URL 구조에 쓰이는 문자까지 모두 인코딩하고, 전체 URL 모드는 주소 구조 문자는 남기고 나머지만 인코딩합니다.
